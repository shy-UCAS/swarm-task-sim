## 2. 下发前原型（规划审查方云端，完整的形状约束）

**做法：**
- 40 族、69 个目标，圆心在警戒区内随机；
- 局部证书 A_j、B_j 同裁定 1；
- 求半径曲线 ρ(φ)：周期三次 B 样条，**M = 120 个控制点**（3° 间隔），在 360 个方位上做下面的线性规划：
  - 约束 A_j ≤ ρ(φ_j) ≤ B_j；
  - 线性化曲率约束 −κ_max·A_j² ≤ ρ − ρ'' ≤ κ_max·A_j²；
  - 目标：最小化 Σ|ρ(φ_j) − t_j|，t_j = A_j + u_j·(B_j − A_j)；
- 求解后用精确极坐标曲率公式 κ = (ρ² + 2ρ'² − ρρ'')/(ρ² + ρ'²)^{3/2} 复核。

**曲率上限：** κ_max = min( κ\*/(1 + κ\*·D), 1/(1.05·15 + D) )
- 第一项：车道曲率 κ/(1 − κD) ≤ κ\*（引导层折线分辨率，κ\* = 0.38 m⁻¹）；
- 第二项：最内车道转弯半径 ≥ 1.05 × 15 m。15 m 是 r4 6.3.5 / V8-10 中 U 形掉头不触发驻留的下界，1.05 为裁定 2 的优化缓冲。它同时保证车道不翻转（κD < 1）。

| 队形 | 可行（LP 有解且精确曲率复核通过） | 精确曲率复核失败 |
|---|---|---|
| 单机 / 纵列（D = 0） | 66/69 | 0 |
| 4 机横排 | 61/69 | 0 |
| 8 机横排 | 53/69 | 0 |
| 12 机横排 | 44/69 | 0 |
| 12 机横排，不行时退到纵列 | **66/69** | 0 |

不可行的情形主要是管区间为空（宽队形放不下），由队形退让解决；另有 1 个目标完全没有环形可行带（只能折返）。

## 3. 修订

**3.1 形状构造改为带曲率约束的线性规划（取代裁定 1 第 5 条，以及指令 2.3 的"360 控制值正基平均"）。**

1. **表示：** 半径函数用三次 B 样条。环绕拓扑用周期样条，M = 120 个控制点（3° 间隔；来源：本原型，能抹平 1° 级台阶，又能跟随环带）；折返弧用同间隔的夹持样条，范围只覆盖弧所在的方位段。
2. **约束**（在每个方位 j 上，以及相邻两方位的中点上，中点用相邻两行区间的交集）：
   - A_j ≤ ρ ≤ B_j；
   - −κ_max·A_j² ≤ ρ − ρ'' ≤ κ_max·A_j²，κ_max 按第 2 节公式，D 为当前队形的车道半跨。
3. **目标：** 最小化 Σ_j |ρ(φ_j) − t_j|，t_j = A_j + u(φ_j)·(B_j − A_j)。u 用裁定 5 的 K 基 logistic 随机函数，是多样性的来源。
4. **求解器：** `scipy.optimize.linprog(method="highs")`。SciPy 已在 `llm` 环境中，不装包。
5. **复核：** 求解后照常运行原 `_ring_ok` 三项，并在 1440 个方位上复核精确曲率（κ·(D + 1.05·15) ≤ 1，车道曲率 ≤ κ\*）。复核失败如实计为 `patrol_shape_audit`。
6. **线性化是否保守：** 线性化不保证保守，以精确复核为准；原型中 0 次失败。

**3.2 选队形用同一检验：** 对某个队形（车道半跨 D），只要 3.1 的线性规划有解（不必看目标值），该队形就可行。按"倾向 → 梯形 → 纵列"取第一个可行的；梯形步长仍按指令二分，判定换成这一检验。这取代裁定 1 第 4 条的"A_j ≤ B_j"。曲率失败不再出现在选队形之后。

**3.3 预置测试 `test_phase_ratio_and_along_projection` 末两条：** 授权修改为按裁定 7 的预期：比值 = 1.0，原因字段为 None。只改这两条断言，修改前后的 SHA256 与 diff 入库。

**3.4 其余不变：** 掉头整体集合（193/193 非空，工作正常）、第 4、5 部分、第 6 部分 D.5 的四个阈值、第 7 部分。
