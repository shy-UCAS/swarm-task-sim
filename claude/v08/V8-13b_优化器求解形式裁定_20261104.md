## 2. 修订

**2.1 求解形式：PHR 增广拉格朗日，内层 L-BFGS-B。** 这是轨迹优化中常用的做法，例如 GCOPTER 用 PHR-ALM 加 L-BFGS 处理不等式约束。

- **目标：** f = F_ref + λ_j·F_smooth（定义同 V8-13 指令 3.3）。
- **不等式约束 g_k(c) ≤ 0：** 无量纲，采样点与 V8-13 第 3.3 节相同，阈值用附录裁定 2 的缓冲值：

  | 约束 | g_k |
  |---|---|
  | 间距 | (3.25 − d)/3 |
  | 几何 | −(g_c − 1)/m_c |
  | 速度 | ‖v‖/(0.95·12) − 1 |
  | 法向加速度 | a_n/(0.95·3) − 1 |
  | 切向加速度 | \|a_t\|/(0.95·2) − 1 |
  | 加加速度 | ‖j‖/(0.95·J_plan) − 1 |

- **增广函数：** L(c; λ, ρ) = f + (ρ/2)·Σ_k max(0, g_k + λ_k/ρ)² − Σ_k λ_k²/(2ρ)。解析梯度沿用现有链式法则。
- **外循环：**
  1. 初值 λ_k = 0、ρ = 1。理由：约束和目标都已无量纲化，单位尺度下取 1。
  2. 每轮内层求解后，更新乘子 λ_k ← max(0, λ_k + ρ·g_k)。
  3. 若最大违反量没有降到上一轮的 1/4 以下，则 ρ ← 10ρ。这是 Nocedal & Wright 第 17 章的常用更新方式。
  4. **外循环最多 8 轮。** 由此 ρ ≤ 10⁷ < 1/√ε，使条件数保持在 float64 能可靠表示的范围内。
  5. 每轮结束后用**原阈值**做硬检查（V8-13 指令 3.6 + 附录第 4 节），通过即结束。
- **内层：** L-BFGS-B，每轮 maxiter 200，ftol、gtol 用 SciPy 默认值（来源：SciPy 文档），从上一轮的解热启动。预条件化、初始化破对称、等式消元保持不变。
- **成功判定：** 结果有限，且硬检查全部通过。SciPy 的 success 标志只记录，不作判定。外循环用完仍不过，本次尝试失败，原因记为 `optimize_residual`（附最坏约束）。

**2.2 λ_j = 1。** 取消 E/Q 规则。F_ref 与 F_smooth 都已按物理尺度无量纲化（3 m、J_plan），取 1 表示两者在单位尺度上同等重要。依据：V8-13 开发期观察，λ_j = 1 时迭代次数降为原来的约五分之一。标定中报告优化相对骨架的偏离分布，用于检查多样性是否被压平。

**2.3 取消 μ = 2^k 搜索。** 乘子由增广拉格朗日自适应，不再需要。第 3 部分的标定改为：
- 用 2.1、2.2 的固定设置，把全部夹具各跑一次；
- **要求：** h = 1（生产用的间隔）下，所有应成功的夹具都通过硬检查；
- h = 0.5 只作诊断报告。这放宽了上层要求 D.2.4 中"两种 h 都收敛"的要求，规划审查方确认；
- 不满足时停在第 3 部分报告，不进入快速批次。

**2.4 修正大夹具。** 交叉 4 人、12 人夹具中，相邻成员对的横向平移由 D_lane（3 m）改为 15 m，即 S1.5 横向间距的下限（`lateral_spacing_m` 的取值范围为 U[15, 25] m），代表真实的队形间距。保留对向交叉的部分。若预置测试中写死了旧的夹具构造、μ 搜索或 E/Q 规则，相关断言按指令修订处理：在报告中列出，不改测试，由规划审查方审查。

**2.5 参考时间分配留余量。** 骨架的名义时间，用 a_lat_ref = 0.9 × 3.0、a_lon_ref = 0.9 × 2.0 调用同一个 `speed_profile`。只改调用参数，不改 `v08/sim/` 文件。理由：参考轨迹须严格落在缓冲后的上限（0.95 倍）之内，固定时间与两端 a = 0 下才有可行余地（GPT 第 9.3 节，冒烟实测 2.16 > 2）。这属于工程余量。
