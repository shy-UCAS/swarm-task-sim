# SimpleGC 使用说明

## 1. 启动 SITL

先运行仿真程序：

```powershell
.\ArducopterSITL\ConsoleApp1.exe
```

等待 SITL 启动完成，并确认连接配置文件中第一个端口可用：

```text
ArducopterSITL\TCP -local.port
```

当前默认连接第一个地址：

```text
tcp://127.0.0.1:11010
```

## 2. 运行主程序

打开新的 PowerShell 终端，进入项目根目录：

```powershell
python .\main.py
```

程序会自动：

- 读取 `loadData\uav_trajectories_persistent_20260213_164652.json`
- 生成任务列表
- 连接 `ArducopterSITL\TCP -local.port` 中第一个无人机端口
- 上传每个任务的 mission
- 按 10Hz 记录飞行状态
- 每个任务完成后保存一个 CSV 文件

## 3. 输出文件

记录文件保存在：

```text
saveData
```

每个任务一个 CSV 文件，文件名为任务名，例如：

```text
saveData\agent_1_0.csv
```
