## 预计时长

建议预留 **1–1.5 小时**，这是安排时间的估算。历史有效 259/260 次运行平均约 256 秒，20 任务两路的理想值约 42.7 分钟；假定并行效率 80%–90%，约 47–53 分钟，另加统一导出、审计、描述与加载收尾。新种子、并行负载和重试会改变实际耗时；本轮尚无并行实测。历史依据见[执行方案第 10 节](v0.6_parallel_execution_plan.md)。

## 新 pwsh 窗口：运行、记录日志并正常收尾

下列整块可直接复制。它先激活 `llm`，以前台 Python 运行；只有 run 正常完成且台账无停止原因时才执行 finalize。`run` 本身不会自动 finalize。控制台转录日志写入批次目录，并用时间与随机后缀避免覆盖。

```powershell
$ErrorActionPreference = 'Stop'
if ($PSVersionTable.PSVersion.Major -lt 7) { throw '请在 PowerShell 7 (pwsh) 中执行。' }
$PSNativeCommandUseErrorActionPreference = $false
(& 'C:\Users\shy\anaconda3\Scripts\conda.exe' 'shell.powershell' 'hook') | Out-String | Invoke-Expression
conda activate llm
if ($env:CONDA_DEFAULT_ENV -ne 'llm') { throw 'llm 环境未成功激活。' }
$env:SIM_DATA_ROOT = 'F:\CASIA\Drone Swarm Situational Awareness Algorithm\SwarmData'
$env:PYTHONDONTWRITEBYTECODE = '1'
Set-Location -LiteralPath 'F:\CASIA\Drone Swarm Situational Awareness Algorithm\Simulation-dev\Multi-UAV SimpleGC'
$pilotBatchId = 'v06_pilot20_20261007_seed2026100701'
$pilotBatchDir = Join-Path $env:SIM_DATA_ROOT ('parallel_batch\' + $pilotBatchId)
if (-not (Test-Path -LiteralPath (Join-Path $pilotBatchDir 'plan.json'))) { throw '找不到已准备的批次。' }
$pilotLogName = 'console_' + (Get-Date -Format 'yyyyMMdd_HHmmss') + '_' + [guid]::NewGuid().ToString('N').Substring(0,8) + '.log'
Start-Transcript -LiteralPath (Join-Path $pilotBatchDir $pilotLogName) -NoClobber
try {
    python -u -B scripts/run_parallel_batch.py run --batch-id $pilotBatchId
    $pilotRunExit = $LASTEXITCODE
    if ($pilotRunExit -ne 0) { throw "run 已停止或失败（退出码 $pilotRunExit）；保留证据，不继续 finalize。" }
    $pilotControl = Get-Content -LiteralPath (Join-Path $pilotBatchDir 'control.json') -Raw -Encoding utf8 | ConvertFrom-Json
    if (-not $pilotControl.completed -or $pilotControl.stopped_reason -or $pilotControl.finalized) {
        throw '台账不满足首次 finalize 条件；先核对状态。'
    }
    python -u -B scripts/run_parallel_batch.py finalize --batch-id $pilotBatchId
    if ($LASTEXITCODE -ne 0) { throw 'finalize 失败；保留全部文件供事后分析，不反复重试。' }
    $pilotControl = Get-Content -LiteralPath (Join-Path $pilotBatchDir 'control.json') -Raw -Encoding utf8 | ConvertFrom-Json
    $pilotReport = Get-Content -LiteralPath (Join-Path $pilotBatchDir 'final_report.json') -Raw -Encoding utf8 | ConvertFrom-Json
    if (-not $pilotControl.completed -or -not $pilotControl.finalized -or $pilotControl.stopped_reason -or
        $pilotReport.total -ne 20 -or -not $pilotReport.description_check.consistency_pass) {
        throw '收尾完成条件未全部满足；请保留报告供分析。'
    }
    Write-Host ('20 个任务已完成统一收尾：' + (Join-Path $pilotBatchDir 'final_report.json'))
    Write-Host ('审计问题数（仍需事后复核）：' + @($pilotReport.audit_issues).Count)
} finally {
    Stop-Transcript
}
```

控制台可能长时间安静：各执行进程的详细输出保存在 `shards\shard_XX\attempts\aXXXXXX\worker.log`，总控制器主要在退出时打印汇总 JSON。不要因控制台安静重复启动 run。试跑期间不要改动受保护源码、配置或冻结包，也不要切换分支／拉取代码。

## 判断收尾完成与中途停止

**正常全部收尾完成**：批次目录中存在 `final_report.json`，且 `control.json` 的 `completed=true`、`finalized=true`、`stopped_reason=null`；报告 `total=20`、`description_check.consistency_pass=true`。报告绑定统一数据集／语言清单哈希；`dataset/`、`language/`、`dataset_audit.json` 是主要分析产物。`audit_issues` 和质量不合格记录仍需事后复核，收尾完成不等于 20 条全部质量合格。锁文件继续存在是正常的，不能据此判断进程仍在运行。

**中途需要停止**：在运行 run 的前台窗口按 **一次 Ctrl+C**，保持窗口打开，等待命令自行退出。控制器会停止派发新任务，让已经启动的执行进程完成降落、清理、分析和保存；Windows 执行进程采用独立进程组。不要反复 Ctrl+C、关闭终端或按进程名批量 kill。此做法依据现有实现和已通过的离线中断测试，本次未启动 SITL 实测中断。

正常停止收尾后，`stop_report.json` 记录停止原因，`draining_attempts=[]`，`control.json` 中所有已登记 attempt 的 `status` 为 `finished`。这表示已启动任务收尾完毕，不表示全部 20 任务完成。停止状态会保留，`--resume` 不会清除停止原因；不要手改台账、补飞或直接 finalize。保留日志和目录，交由事后分析。

如果 run 已经正常完成，只是还没有执行 finalize，可在上面 status 窗口确认 `completed=true`、`finalized=false`、`stopped_reason=null` 后，单独复制以下块；**仅执行一次，不重新 run**：

```powershell
# 接在上面的 status 环境设置之后。
$pilotBatchDir = Join-Path $env:SIM_DATA_ROOT 'parallel_batch\v06_pilot20_20261007_seed2026100701'
$pilotControl = Get-Content -LiteralPath (Join-Path $pilotBatchDir 'control.json') -Raw -Encoding utf8 | ConvertFrom-Json
if (-not $pilotControl.completed -or $pilotControl.finalized -or $pilotControl.stopped_reason) { throw '当前状态不允许 finalize。' }
$pilotFinalizeLog = Join-Path $pilotBatchDir ('finalize_' + [guid]::NewGuid().ToString('N') + '.log')
Start-Transcript -LiteralPath $pilotFinalizeLog -NoClobber
try {
    python -u -B scripts/run_parallel_batch.py finalize --batch-id v06_pilot20_20261007_seed2026100701
    if ($LASTEXITCODE -ne 0) { throw 'finalize 失败，请保留证据。' }
} finally { Stop-Transcript }
```

## 可选：每 30 秒采样整机 CPU 与内存

这是用户自行启动的轻量 OS 采样，不查询仿真状态，也不操作仿真进程。可在独立 pwsh 窗口复制以下块，然后保持该窗口打开；不需要 Conda。记录整机 CPU 百分比、已用／可用物理内存，后台作业每 30 秒追加一行到批次目录，不据此判断仿真结束。

```powershell
$ErrorActionPreference = 'Stop'
if ($PSVersionTable.PSVersion.Major -lt 7) { throw '请使用 PowerShell 7。' }
$pilotSampleDir = 'F:\CASIA\Drone Swarm Situational Awareness Algorithm\SwarmData\parallel_batch\v06_pilot20_20261007_seed2026100701'
if (-not (Test-Path -LiteralPath (Join-Path $pilotSampleDir 'plan.json'))) { throw '批次不存在。' }
$pilotSamplePath = Join-Path $pilotSampleDir ('host_resources_' + [guid]::NewGuid().ToString('N') + '.csv')
$pilotSampleJob = Start-Job -ArgumentList $pilotSamplePath -ScriptBlock {
    param($outputPath)
    $ErrorActionPreference = 'Stop'
    while ($true) {
        $cpuSample = Get-CimInstance Win32_PerfFormattedData_PerfOS_Processor -Filter "Name='_Total'"
        $memorySample = Get-CimInstance Win32_OperatingSystem
        [pscustomobject]@{
            utc = [DateTime]::UtcNow.ToString('o')
            cpu_percent = $cpuSample.PercentProcessorTime
            memory_used_mib = [math]::Round(($memorySample.TotalVisibleMemorySize - $memorySample.FreePhysicalMemory) / 1024, 1)
            memory_available_mib = [math]::Round($memorySample.FreePhysicalMemory / 1024, 1)
        } | Export-Csv -LiteralPath $outputPath -Append -NoTypeInformation -Encoding utf8
        Start-Sleep -Seconds 30
    }
}
Write-Host ('资源采样日志：' + $pilotSamplePath)
```

仿真与 finalize 结束后，回到采样窗口执行下列命令，仅停止该采样作业。若 CSV 不增长，`Receive-Job` 会显示采样错误；这不影响仿真。

```powershell
Stop-Job -Job $pilotSampleJob
Receive-Job -Job $pilotSampleJob
Remove-Job -Job $pilotSampleJob
```

运行结束或中止后，向助手提供批次 ID 即可开展事后分析；助手不会自动轮询或接续运行。
