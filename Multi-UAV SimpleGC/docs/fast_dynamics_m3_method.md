# M3 r2 未校准基线：本轮方法登记

用户于 2026-10-12 授权使用已有 r2 调参来源。本轮只完成固定划分、缺省参数基线、调参方法及数值门槛建议，然后等待确认；不实际调参，不执行内部留出或高速能力检查。M2-02B 两组均封存，不读取、不飞行；不启动 SITL。

划分先于质量筛选：从 r2 plan 的 family 集合排除 T1/T4 plan 共用的 14 个 family；按 SHA256(UTF-8(`2026101205|` + family_id)) 排序，并列按 family_id 排序，前 \(\lfloor 7G/10\rfloor\) 个归调参，其余归内部留出。种子固定为 **2026101205**，不得重抽。整族的三个意图、所有后端及重复飞行同组。内部留出是已见来源的过拟合检查集，**非严格盲测**。划分单独保存，不替换 M2-02B 索引。

访问顺序：先冻结身份名册，再筛选调参 family 的最终尝试；仅打开其运行目录，先检查质量，再读取合格参考轨迹。缺失/不合格逐项保留。r1 同任务只能作为重复测量，不能增加独立任务/family 分母。fastsim 输入与 r2 输入原字节绑定，重新编译后的实际航线必须等于保存规划；不可复制 SITL 结果标签。

时间沿用 T1 方法：每个旧运行选择自然编号最小、有效且支持起点的参考机，将其分段时钟模型求逆，减去飞行起点的源秒，得到共同仿真秒；不外推、不统一乘 0.975。只比较空中任务的匹配执行阶段，总时长同时给出端到端共同任务窗口与阶段口径，起降不计入 fastsim 误差。速度优先由位置对仿真秒作差分，不拟合 FCU 速度已知尺度残差。

指标：真值/观测成功及各条件、运动模式槽位分别比较；未知单列。阶段/圈次/有序航段约束下以弧长对齐横向偏差，报告匹配覆盖率；时长和机间距保持原共同时间，不能用逐机弧长重排计算间距。巡航与转弯速度使用固定位置差分和规划窗口，缺失不填零。先逐任务汇总，再给任务与 family 等权分布；不把帧当独立样本。

默认动力学参数不变。通过标准是本轮结束时结合基线、r1/r2 自然波动及任务尺度提出的**待批准数值建议**，不追认缺省模型通过。性能改动暂停；重复约束计算和描述耗时留待 v0.7 试产后评估。参数正式冻结后，内部留出和用户指定 4/7/10 m/s 合成高速检查均须另行启动。
