另对已有 v0.4 V06 数据集做只读兼容性核查：10/10 个 episode 可抽取事实，10/10 判为平行扫描；返航可见事实为 true 6/10、false 4/10，逐项双通道分歧为 0。明细与源 manifest 哈希见 [`v04_compatibility.json`](../tmp_v05/l/v04_compatibility.json)。该检查不表示旧协议可用于 v0.5 `describe` 导出。

已知边界：本阶段尚无 v0.5 的真实 SITL 轨迹；模式检测阈值是固定版本的几何规则，不等同意图识别模型；`arrival_s` 的既有兜底定义和约 1 秒阶段边界精度没有改变。历史 v0.4 数据只供只读兼容性核查，不能记作本轮 v0.5 验证运行。
