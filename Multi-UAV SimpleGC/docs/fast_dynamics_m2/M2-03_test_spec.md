## 2. 确定性、h与h/2和时钟

### 2.1 步长收敛

后续以同一输入、配置（只改步长）比较 \(h=0.02\) s 与 \(h/2=0.01\) s，按规范agent ID和共同仿真时间对齐：

| 指标 | 门槛/要求 |
| --- | --- |
| 共同网格实际位置差p99 | ≤0.02m |
| 共同网格实际速度差p99 | ≤0.02m/s |
| 对应事件时刻差 | ≤0.02s；相同语义/阶段/机/有效epoch匹配 |
| 每次运行公共网格 | \(t_k=100000k<end\_us\)，帧数 \(\lceil end\_us/100000\rceil\)，零时长0帧 |
| end_us与帧数 | **h/h2不要求相等**；分别核验网格，报告结束差，受终止事件时差约束 |
| 公共区间外尾段 | 单列时长、状态和事件，不能隐去后宣称完全一致 |
| 拐角速度 | 报告实测最小值，不保留0.23/0.35/0.399m/s等不成立的统一下限 |

若事件拓扑或reset次数不同，单列差异，不强行按同名事件配对。end_us=99999/100001相差2µs，却应有1/2帧，是合法反例。M2-04至少做直角和180°单机对照，后续逐阶段扩展。控制改变按设计共同前缀提交，不能把检测时间假装实际控制生效时间。

### 2.2 同构确定性

相同构建/配置/输入下，重复运行、机输入排列、任务派发顺序和worker=1/2应得到逐位一致的规范轨迹/事件摘要。仅剔除run ID、wall time等非物理字段。因果生成 `event_seq`，按 `(t_us,event_seq)` 展示；不以event_name字母序重排reset/confirmed。

### 2.3 物理、输出与证据

真实p/v/a始终积分，不投影回路径、不冻结等待机、不为达标裁状态。按profile分别检查水平/垂向加速度界和jerk向量范数；速度、世界高度、间距、路径/时长与质量也独立检查。无NaN/Inf。support包含任务真实起终点、公共采样点及必要事件点；10Hz输出严格属于 \([0,end\_us)\)。坐标ENU、时间秒明确，`training_eligible=false`。绑定实际源码文件哈希，不仅记录Git HEAD。

## 3. 路线与有序进度oracle

### 3.1 几何、弧长和物理界

正式设计是直线、五次Bézier平滑过渡与明确停车折返节点。普通顶点切距
\[
d_i=\min(0.25,\ 0.1L_{i-1},\ 0.1L_i)\ {\rm m}.
\]
曲线两端曲率为0，与零切向加速度的直线连接时参考加速度连续；不宣称snap连续。统一坐标必须使用实际弧长，不把原折线切掉的 \(2d_i\) 当曲线长度。后续弧长表/逆映射采用自适应阶数或细分求积，明确误差准则、细分上限和不收敛拒绝；一般角度包含150°和174.9°，不能从90°固定64点结果泛化。

恢复原普通EN路线偏差界≤1.0m，B1/B3更紧界见下表；不得改为2.0/2.5m处理反例。圆曲线 \(v\le\min(\sqrt{ar},(jr^2)^{1/3})\) 仅用于解释必要界，不是新Bézier充分保证。一般曲线按设计 \(K,K_s\) 及联合加速度/jerk预算检查，不能同时用满法向与切向能力。参考误差界、实际跟踪误差和最终到达判据分开。

### 3.2 原节点独立球门

保留每机每阶段的**展开原节点顺序**。闭环重合空间点仍是不同序列节点，不按坐标去重或leg取模。中间节点EN球门半径：
\[
\epsilon_i=\min(0.5,\ 0.2\min(L_{i-1},L_i))\ {\rm m}.
\]
端节点用可用相邻边确定半径。独立检查器从实际dense p多项式求球门进入/退出，或用有严格误差界的自适应细分；10Hz近点、跟踪器事件本身不够。第 \(i+1\) 门证据必须在第 \(i\) 门之后，保留轨迹片段及根区间。相邻不重叠球门间真实连续位移至少为 \(L_i-\epsilon_i-\epsilon_{i+1}\)。回退、横偏、跳门与跨圈单列。

0.106227234m短段两端门半径约0.021245447m，互不重叠；真实位移下界约0.06373634m。1m终点容差同时涵盖两点不能证明短段穿越。B4必须拒绝同一位置/时刻被声称通过两门或只有两个leg_advanced事件的伪证据。

进度只用EN，U独立真实控制/积分；终点到达仍用**原目标全3D距离与真实速度**。preview只生成控制目标，不能授予完成证据。未到终点门即移到(30,100)不能为(0,0)→(30,0)取得完成证据。若过去已真实通过末门，之后离开，保留历史route_complete资格，但当前到达谓词Q=false，不能确认或过屏障。旧反例中的累计进度29.95不等同于真实末门证据。闭环起点静止不能直接获得一整圈资格。

起点获取/回退恢复另加最小例：真实位置在设计的有限起点获取域内、位于原语起点后方且v/a为0时，允许重新进入当前原语的前向preview；不得以“投影仍为任意负值”永久保持向起点渐近追踪。普通原语已正向越过出口但没有合法见证时，即便仍在0.5m管道内，也必须恢复到该原语入口有限获取域再执行，不能追出口/最近点并等待不会再发生的正向穿面。参考开始前移不增加物理证据，未真实进入后续门不得完成。折返进入corner_rest同样依有限原角门，不能等待零速终点的精确出口越面。

### 6.1 六格侦察的可证伪因果链

现注册coverage谓词按真实高度是否位于takeoff_alt±height_tolerance选覆盖足迹，完整性使用未过滤原始轨迹。因此U越带可导致服务失败，区别于执行方删除观测。
