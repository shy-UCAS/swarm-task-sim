# M2-02B 新来源补充：生成前方法登记

日期：2026-10-12。用户已授权按修正计划实施新来源；原 M2-02 的 r2 剩余来源限制在本补充阶段改为新生成来源。旧 M2-02 BLOCKED 回执、原划分及修复证据保持不变。

## 固定生成约定

- 沿用 `tri_intent_v06_production.json` 经 `normalize_profile` 得到的全部采样分布、任务模板、规划准入和最多 20 次候选尝试；仅将 master_seed 改为 **2026101203**、base_scene_count 改为 **144**。144 是事先确定的固定批量，接近原 143 个候选，不是保证获得指定划分数量的指标。
- 生成器仍为现有 `generate_v2`；三意图、2/3/4 机及四种合法飞法按现有规则抽样。只生成 TaskSpec、静态编译场景和规划准入记录，不运行飞行、观察器诊断、成败判定、性能测试或参数拟合。
- 全批只生成一次；规划重试属于原生成规则。泄漏排除后不补抽、不换种子、不为平衡飞法或机数重抽。
- 在生成之前，将归一化 profile、源代码 SHA256、历史输入索引 SHA256 和本方法 SHA256 写入外部全新 attempt 的 registration.json；生成命令必须显式提供该文件的预期 SHA256，身份变化即拒绝。

## 历史排除范围

使用 M2-02 修复后 `source_records.json` 的全部 6,380 条 batch 绑定任务路径，以及 `file_scan_inventory.jsonl` 中 purpose 为 generated_input / known_development_fixture 的任务输入。另包含本项目 missions/v3 模板。逐文件验证现有字节与登记 SHA256；只读取任务输入，不读取轨迹、标签、质量、描述和运行结果。

known_development_fixture 中三个按文件名明确登记的非 TaskSpec 文件（h02_v04_normalization_hashes.json、intent_registry_DR130_golden.json、v05_example_loader_baseline.json）及其历史副本只登记排除，不在生成流程中打开。v2 TaskSpec 的 platform 位于顶层，几何身份计算时仅将该字段投影到 scenario.platform；保留原文件及其旧 family_id，不把投影身份冒充原始 ID。其余不支持的结构仍须停止。

范围内所有历史输入一律作为排除来源，无论曾执行、诊断或仅规划。相同文件按路径去重，相同规范场景按 SHA256 合并；裸 mission_id 不作为连接键。损坏、丢失、无法解释的输入导致停止，不能静默放入候选。旧范围之外的来源尚无穷尽性保证。

## 关联与近重复规则 rect_relative_d4_v1

1. 保留实际 scene_content_v1 family ID 和完整规范场景 SHA256；检测短 ID 碰撞。同 family / 同规范场景必然关联。
2. 新批同一 base 的所有候选（包括规划拒绝候选）属于同一谱系；不使用与旧批相同的裸 base_index 建跨批边。
3. 几何比较使用以矩形区域中心为原点的飞机二维位置，单位米；忽略名称、编号、列表顺序、整体平移、朝向、平台/高度/世界边界。忽略这些字段会扩大排除范围，不用改变它们制造新留出。
4. 枚举矩形平面的 8 个 D4 变换（90 度旋转及镜像）；变换时交换宽高。宽、高差均不超过 **1.0 m**，且同机数飞机存在一一匹配、各对欧氏距离均不超过 **1.0 m**，建立近重复边。浮点比较容差仅为 1e-9 m，不先量化或依赖分箱边界。
5. 历史多矩形场景逐矩形作视图，保留全部飞机；忽略额外区域/禁区会扩大排除范围。未知非矩形结构不自动跳过；登记并停止处理。新来源必须是单矩形、无禁区、2/3/4 机。
6. 将新候选之间的几何边、base 谱系边及旧输入关联取传递闭包。凡与旧来源相连的整个新分量排除；没有被规划接纳任务的分量不进入划分。旧—旧近重复边不需计算：两端本来全部排除，无法改变任何新分量是否接触旧来源。

本规则不声称识别任意尺度变化或非矩形拓扑的全部近重复。阈值在生成前固定；不根据排除数量更改。

## 固定划分及访问边界

继续使用 seed **2026101202**。每个合格连通分量的全部实际 family ID 去重后按 Unicode 码点排序，以 `json.dumps(ids, ensure_ascii=True, separators=(',', ':'))` UTF-8 SHA256 得到 component_id；rank 为 `SHA256(UTF8('2026101202|' + component_id))`。按 `(rank, component_id)` 排序，前 floor(G/2) 个校准，其余盲测。G<2 则 BLOCKED。

按连通分量分组，不能拆开候选谱系；同时报告分量数、全部 family 数、接纳 family 数和可用 TaskSpec 数。两组均标 `NOT_RUN`，`actual_result=null`，`reference_episode_available=false`；冻结输入不表示已获得 M3 对照轨迹。

登记、生成及冻结均使用拒绝覆盖的新目录/文件；旧版原字节保留。仓库内仅保存代码、合成测试、小型摘要、方法/报告与新划分索引；全量输入、清单和原始日志存于 SwarmData/fast_dynamics。
