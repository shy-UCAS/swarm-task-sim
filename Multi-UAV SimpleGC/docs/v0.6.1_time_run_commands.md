## 3. 完成后验收与首次 finalize

完成标志须确认控制器真正启动并返回，且在飞为零。此后才读 control 与尝试证据。仅 `completed=true`、无 paused/stopped、全部执行完成、尚未 finalized 时允许首次 finalize；退出码 0 不等于通过。

```powershell
# 仅完成标志确认控制器结束后执行。
$control = Get-Content (Join-Path $batchDir 'control.json') -Raw | ConvertFrom-Json
if (-not $control.completed -or $control.paused -or $control.stopped_reason -or $control.finalized -or
    @($control.attempts | Where-Object status -ne 'finished').Count) { throw 'Not eligible for first finalize' }
& $condaExe run -n $projectEnv --no-capture-output python -B scripts/run_parallel_batch.py finalize --batch-id $batchId
if ($LASTEXITCODE -ne 0) { throw 'Finalize failed; preserve evidence, do not retry blindly' }
```
