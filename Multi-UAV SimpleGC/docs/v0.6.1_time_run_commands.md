# v0.6.1：T1／T2／T3 验证命令模板

**本轮仅实现代码和离线测试，未 prepare、未 run、未 resume、未 finalize 任何验证批次。** 本页对应 [任务计划第 3 节](v06_time_contract_plan.md)，须先通过实施复核，再由用户授权具体组别与新批次。批次 ID、尝试预算和存储估算尚未决定，下面留空／置零并在执行前拒绝缺失值，不沿用 A 的旧预算。

| 组别 | 并行数 | SITL 倍率 | 前置条件 |
| --- | --- | --- | --- |
| T1 | 2 | 1 | 实施复核与独占机器检查通过；与 r2 同任务比较 |
| T2 | 2 | 2 | T1 通过第 3.1 节标准后，单独授权 |
| T3 | 4 | 2 | T2 余量充足且通过标准后，单独授权 |
| T3-3x（可选追加） | 4 | 3 | T3 的 2 倍配置通过且资源余量充足后，单独授权 |

合成测试的 1／2／4 倍覆盖不等于已授权 4 倍运行；实际验证组按上表。每组选择相同的 42 个任务，通过 `docs/v06_accel_mission_ids.json` 导入 r2 完整 bundle，逐文件哈希保持不变；`execution_override` 冻结新的 v0.6.1 协议和倍率，不改写源输入。子集批次自动标记 `purpose=pilot`、`training_data=false`。

每组依次人工执行准备、复核、运行、收尾、验收，**不把这些步骤串成自动流水线**。r1／r2／A 和已收尾 pilot 不重新 prepare、不续跑、不回写；不能用回退源码、覆盖计划或清空台账绕过冻结检查。

## 1. 共用配置（授权后填写）

使用 PowerShell 7，工作目录为 `Simulation-dev/Multi-UAV SimpleGC`。以下变量只属于当前终端；新终端需重新填写。运行前先按计划第 3.2 节独占机器、记录空闲基线，并确认没有其他批次或 SITL。基端口固定 20100：两片使用 20100–20299，四片使用 20100–20499。prepare 和 run 都会探测 TCP／UDP 端口，探测不保留端口。

```powershell
$ErrorActionPreference = 'Stop'
if ($PSVersionTable.PSVersion.Major -lt 7) { throw '请使用 PowerShell 7。' }
$PSNativeCommandUseErrorActionPreference = $false
$project = 'F:/CASIA/Drone Swarm Situational Awareness Algorithm/Simulation-dev/Multi-UAV SimpleGC'
Set-Location -LiteralPath $project
$env:SIM_DATA_ROOT = 'F:/CASIA/Drone Swarm Situational Awareness Algorithm/SwarmData'
$env:PYTHONDONTWRITEBYTECODE = '1'
$condaExe = 'C:/Users/shy/anaconda3/Scripts/conda.exe'
$projectEnv = (Get-Content -LiteralPath '.conda-env' -Raw -Encoding utf8).Trim()
if ($projectEnv -ne 'llm') { throw '项目环境已改变，先核对。' }
$group = '' # 填入本次已授权的 T1 / T2 / T3 / T3-3x。
$batchId = '' # 填入本次已授权、从未使用的新批次 ID。
$attemptBudget = 0 # 由复核确定；42 至 84，总预算包括允许的起飞前重试。
$bytesPerAttempt = 0L # 由存储估算确定的正整数字节数。
$exportReserveBytes = 0L # 由存储估算确定的正整数字节数。
$groups = @{T1=@(2,1); T2=@(2,2); T3=@(4,2); 'T3-3x'=@(4,3)}
if (-not $groups.ContainsKey($group)) { throw '先填写已授权组别。' }
if ($batchId -notmatch '^[A-Za-z0-9][A-Za-z0-9_-]{0,79}$') { throw '先填写合法的新批次 ID。' }
if ($attemptBudget -lt 42 -or $attemptBudget -gt 84 -or $bytesPerAttempt -le 0 -or $exportReserveBytes -le 0) {
    throw '先填写经复核的尝试预算和存储估算。'
}
$shards, $speedup = $groups[$group]
$batchDir = Join-Path $env:SIM_DATA_ROOT ('parallel_batch/' + $batchId)
$sourceBundle = Join-Path $env:SIM_DATA_ROOT 'parallel_batch/v06_production900r2_seed2026100812/bundle'
```

## 2. 只做 prepare，然后复核

先确认 HEAD／标签 `v0.6.1-time` 的运行源文件一致、远端 CI 通过、工作区干净。若标签之后仅增加报告，应核对受保护运行文件而不是自行回退源码。准备时冻结文件集，后续运行不得改源码、参数或输入。

```powershell
if (Test-Path -LiteralPath $batchDir) { throw '目录已经存在；禁止覆盖或再次 prepare。' }
& $condaExe run -n $projectEnv --no-capture-output python -B scripts/prepare_parallel_subset.py `
    --source-bundle $sourceBundle --mission-ids docs/v06_accel_mission_ids.json `
    --batch-id $batchId --shards $shards --base-port 20100 `
    --protocol-version v0.6.1 --sim-speedup $speedup --startup-stagger-host-s 30 `
    --max-attempts $attemptBudget --storage-bytes-per-attempt $bytesPerAttempt `
    --export-reserve-bytes $exportReserveBytes
if ($LASTEXITCODE -ne 0) { throw 'prepare 未成功；保留错误与目录，不自动重试。' }
```

准备后独立核对 42 任务、pilot／非训练标记、冻结配置和 plan 哈希，并再次核对导入 bundle 全部文件。此检查不启动仿真。

```powershell
$checkCode = @'
import sys
from pathlib import Path
from swarm_sim.parallel_batch import load_plan, integrity
from swarm_sim.parallel_subset import tree_hashes
from swarm_sim.generation import file_hash
plan = load_plan(Path(sys.argv[1]))
integrity(plan)
assert len(plan['tasks']) == 42 and plan['purpose'] == 'pilot' and plan['training_data'] is False
assert plan['execution_override'] == {'protocol_version':'v0.6.1', 'sim_speedup':float(sys.argv[3])}
assert plan['shards'] == int(sys.argv[2]) and plan['base_port'] == 20100
assert plan['startup_stagger_host_s'] == 30
actual = tree_hashes(plan['bundle'])
assert actual == plan['subset']['source_bundle_sha256'] == tree_hashes(plan['subset']['source_bundle'])
print({'batch_id':plan['batch_id'], 'plan_sha256':file_hash(Path(plan['root'])/'plan.json'),
       'bundle_files_matched':len(actual), 'tasks':len(plan['tasks']), 'ports':plan['ports']})
'@
& $condaExe run -n $projectEnv --no-capture-output python -B -c $checkCode $batchDir $shards $speedup
if ($LASTEXITCODE -ne 0) { throw '冻结配置或 bundle 核对失败，不能运行。' }
```

## 3. run／显式 resume（会启动仿真，等待后续授权）

每次执行前确认独占机器和剩余磁盘空间。运行参数从冻结 plan 读取，run 不再接受 `--base-port`、`--sim-speedup` 或协议覆盖。分片首个任务按 \(k\times30\) **主机秒** 错峰；任务内部机间出发偏移按**仿真秒**定义。转录写入批次外 `SwarmData/agent_work/<batch-id>/console_*.log`，不写入 bundle 或历史批次。

```powershell
$operation = '' # 后续明确授权后填 run；已排空且复核通过的暂停才填 resume。
if ($operation -notin @('run','resume')) { throw '先选择本次已授权的 run 或 resume。' }
$plan = Get-Content -LiteralPath (Join-Path $batchDir 'plan.json') -Raw -Encoding utf8 | ConvertFrom-Json
$control = Get-Content -LiteralPath (Join-Path $batchDir 'control.json') -Raw -Encoding utf8 | ConvertFrom-Json
if ($plan.purpose -ne 'pilot' -or $plan.training_data -ne $false -or @($plan.tasks).Count -ne 42 -or
    $plan.execution_override.protocol_version -ne 'v0.6.1' -or $plan.execution_override.sim_speedup -ne $speedup -or
    $plan.shards -ne $shards -or $plan.base_port -ne 20100 -or $plan.startup_stagger_host_s -ne 30) { throw '冻结配置不符。' }
if ($control.stopped_reason -or $control.completed -or $control.finalized) { throw '停止、完成或收尾批次不得 run/resume。' }
if ($operation -eq 'run' -and (@($control.attempts).Count -ne 0 -or $control.paused)) { throw '已有尝试，禁止再次 run。' }
if ($operation -eq 'resume' -and (-not $control.paused -or @($control.attempts | Where-Object status -ne 'finished').Count)) {
    throw '只恢复已排空、经人工复核的暂停；不可清除停止原因。'
}
(& $condaExe 'shell.powershell' 'hook') | Out-String | Invoke-Expression
conda activate $projectEnv
if ($env:CONDA_DEFAULT_ENV -ne $projectEnv) { throw '项目 Conda 环境未激活。' }
$runArgs = @('run','--batch-id',$batchId)
if ($operation -eq 'resume') { $runArgs += '--resume' }
$logDir = Join-Path $env:SIM_DATA_ROOT ('agent_work/' + $batchId)
New-Item -ItemType Directory -Path $logDir -Force | Out-Null
$logPath = Join-Path $logDir ('console_' + [DateTime]::UtcNow.ToString('yyyyMMddTHHmmssZ') + '_' + [guid]::NewGuid().ToString('N') + '.log')
Start-Transcript -LiteralPath $logPath -NoClobber
try {
    python -u -B scripts/run_parallel_batch.py @runArgs
    if ($LASTEXITCODE -ne 0) { throw '控制器退出非零；保留完整转录和证据，不自动重跑。' }
} finally { Stop-Transcript }
```

按一次 Ctrl+C 请求暂停，保持终端打开直至在飞任务排空。规则暂停同样先复核原因和资源，不能自动 resume；`stopped_reason` 非空的确认违规／基础设施停止不可恢复。转录关闭不等于任务全部完成，也不自动 finalize。

## 4. 只读 status 与另行 finalize

下方 status 每次读取一个快照，不启动后台监视器。

```powershell
& $condaExe run -n $projectEnv --no-capture-output python -B scripts/run_parallel_batch.py status --batch-id $batchId
if ($LASTEXITCODE -ne 0) { throw '状态核验失败，保留现场。' }
```

全部任务完成、无停止原因、尚未收尾后，才按后续授权单独 finalize；不要把它自动附在 run 后。

```powershell
$control = Get-Content -LiteralPath (Join-Path $batchDir 'control.json') -Raw -Encoding utf8 | ConvertFrom-Json
if (-not $control.completed -or $control.stopped_reason -or $control.finalized) { throw '状态不允许首次 finalize。' }
& $condaExe run -n $projectEnv --no-capture-output python -B scripts/run_parallel_batch.py finalize --batch-id $batchId
if ($LASTEXITCODE -ne 0) { throw 'finalize 未成功；保留现场，不反复尝试。' }
```

之后按计划第 3.1 节写验证报告；T1 未通过就停下，不进入 T2。最终用于 r3 的配置待各组验证后决定，不能从离线测试推断运行吞吐已达标。
