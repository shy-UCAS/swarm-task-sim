## 异常与处理

没有触发第 10 节的停止条件，未修改测试预期或禁止修改内容。

1. 原登记源根目录没有 provenance.json；发现它按家族存放，读取并核对全部 300 份后使用原主种子，没有代用来源。
2. PowerShell 7 已核实。沙箱内 Conda 启动和工作树 Git 元数据写入失败，转由工具授权边界执行同一已授权命令后成功，未切换 Python 环境。
3. 一次基准生成命令使用 Conda 不支持的多行 `-c` 参数，改为临时脚本后成功；一次 unittest 按包名启动失败，改为项目既有 discover 方式后成功。均发生在候选运行前，未更改被测代码或判据。
4. 新旧地图尺寸数值有 int/float 表示差异，原 batch 汇总可能把 `6000` 与 `6000.0` 分列。派生统计按相同数值合并显示；外部原始汇总、场景和 family 文件保留原样。提交检查发现 PowerShell 生成的两份 JSON 回执为 CRLF，已统一为 LF，数据内容不变。
5. 全量局部挂接提案因 R2 不合格重抽 **23 次**，均未输出为有效场景；300 个家族均在第 1 次完整布局尝试内完成。`sampling_layout_s15_exhausted=0`、`layout_exceeds_max_map=0`、锚点重试 0 次。这是第 5.1 节规定的提案筛选，不是输出 R1/R2 违反。
