# Traj2Language v0.7 S1.1 本地完成报告（2026-10-13）

本轮只修订抽样方式并增加绕行诊断；没有放宽任何原有几何条件或改变公开场景语义。
工作目录仍为 `Simulation-v07scene`，分支 `v07-scene`；未修改 fastsim、SITL、其他工作目录或 CI。

## 抽样修订

- 设施数按 40%/35%/25% 取 1/2/3；地图分别为 4/5/6 km，真实边界写入原公开几何字段。
- 设施轮廓和三层外扩初值不变；在完整预警区域能放入地图且距进场区保留原余量的范围内构造布局。
- 设施位置最多构造 128 次，不换形状、圈层或设施数；约束不松动。
- 限制区逐个放置，每个最多 48 次，成功的保持原样；失败槽跳过并记录次数和具体原因。
- 进场阻挡确实进入选定直线的内部，整区位于进场区安全余量之后、预警轮廓之前。
- 设施旁保持预警部分重叠；设施之间在预警间隙或重叠区域抽取中心；两者及全部限制区均不碰警戒区、不覆盖进场区或其安全余量。
- 雷达只保留地图内合法位置；初始机状态、速度、高度、圈层和余量的既有范围不变。
- 每个完整地图仍运行原来的全部验收；两个新增诊断不决定接受/拒绝。

公开 JSON 保持 `traj2language.public_scene/0.7-s1.1`；生成器为 `traj2language.scene_sampler/0.7-s1.3`。
原 S1 抽样仍可通过 `revision="s1"` 或 CLI `--sampling-revision s1` 重建。
