## 实现与契约

- family 单次采样设施、圈层、三类独立限制区、雷达、机数、初始状态、进场区、公共高度/速度、间距和观测初值。
- 不采样任务单元、任务组数/规模、成员分配、角色、目标或时序。
- 公开 JSON 使用 `traj2language.public_scene/0.7-s1.1`；只有几何、公开实体关联、稳定 ID、ENU 和单位。
- 种子、family/map ID、初始状态、路线和诊断分文件保存；公开 JSON 有递归白名单与 JSON Schema。
- 圈层按轮廓外扩；仅对独立限制区加 30 m 安全余量，以外切包络可见图求最短路。
- 每个进场区到每个设施检查可达；逐设施按 \(5^\circ\) bin 统计可行方位，不以跨度拒绝。
- 每个候选均有 PNG、公开场景、family 初值、来源与检查 JSON，接受和拒绝都保留。

## 限制和保留问题

- 完整圈层留在地图内、进场区保持安全余量是明确记录的几何检查口径；数值仍为初值。
- 候选 1/2/3 设施为 101/87/112，接受为 71/26/10；筛选明显偏向单设施，不据此冻结分布。
- 多设施大圈层与 4 km 地图的结合、限制区相交是较高拒绝率的主要来源；未靠降低约束或无穷重采样掩盖。
- 方位是 \(5^\circ\) 离散 bin 的可达与径向畅通统计，不是连续角度认证。
- 可见图最短路针对保守外切多边形；不是解析圆弧路径的绝对最短路。
- 高度 100–150 m、进场区宽/深 360/100 m、初始速度为公共速度的 0–25% 是已记录、未冻结的工程初值。
- 本轮没有 fastsim 执行，不能以名义几何可达代替运动学或实际多机约束。
