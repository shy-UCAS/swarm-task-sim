## fastsim 配置与能力边界

fastsim 使用 M3 冻结配置 [m3_r2_20261013_v1.json](../../configs/fast_dynamics/m3_r2_20261013_v1.json)。完整验证与限制见 [M3 收尾报告](../fast_dynamics_m3_closeout.md)。

该配置在 2–3 m/s SITL 参考上完成校准；4–10 m/s 属于外推，未经高速 SITL 校准。离线高速用例虽完成且不超动力学上限，10 m/s 仍出现约 4 m 冲出，四机等长汇聚最小间距约 2.93 m；50/100/200 m 圆环会明显减速，尚未证实恒定请求速度下的最小可用盘旋半径。S2 应使用收尾报告中的实测限制作为规划输入，不能以最终到达或目标点间距替代全过程约束。
