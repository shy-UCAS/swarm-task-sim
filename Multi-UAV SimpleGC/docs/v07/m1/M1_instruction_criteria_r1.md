## 0. 项目性质（请先了解）

本项目是**防御方视角的意图识别研究**。生成器只产出带标签的合成轨迹数据集，用于训练模型根据观测轨迹判断来袭集群的行为类别（过境、侦察、游弋监视、佯动、突防）、任务编组和组内同步/递次关系，并生成描述。

- 场景是随机生成的抽象几何（圆形、凸多边形），不涉及真实地点、设施或防空部署。
- 运动后端是平动点质量运动学模型 fastsim，不控制任何真实无人机。
- 规范明确排除雷达规避、进攻航线优化、武器与电子压制。
- **本阶段（M1）只改"标签判定"代码**：根据已经飞完的轨迹判断某种行为是否发生。不涉及任何航线规划，不新增任何飞行能力。

## 7. 精确定义（以设计文档 §2 为准，这里补充实现细节）

### 7.1 记号

- 全部计算在 10 Hz 真值网格上进行。圈层 L 与轮廓有符号距离 d **只**由 `geometry_facts` 给出。
- f* 为该组目标设施；中心 c 取 `center_of(facility geometry)`。
- 作业段 W_i：从首次 L_{f*} ≥ 1 的帧到最后一次 L_{f*} ≥ 1 的帧（含两端）；从未进入则为空。

### 7.2 检测器

**驻留** `dwell(frames)`：存在长度恰为 201 帧（20 s）的连续窗口，窗口完全落在给定帧集合内，并同时满足：

1. 窗口内所有位置到窗口位置均值的距离都 ≤ 30 m；
2. 窗口首帧与末帧位置之间的距离 ≤ 30 m（定稿后勘误 1，见下）。

返回最早合格窗口的起点（`t_s`）、`t_confirm = t_s + 20`、合格窗口并集的总时长（诊断）。

> 定稿后勘误 1（2026-10-15，指导方编写测试时发现，已经用户批准）：只用条件 1 时，4 m/s 的轨迹在一个 90° 转角处，窗口内到均值的最大距离只有 31.6 m（余量 1.6 m），转角超过约 100° 就会被误判为驻留，过境样本将被误判失败。加上条件 2 后，这些转角情形的首尾距离都 ≥ 40 m，不会误判；悬停、小圈盘旋、进场末段接悬停的情形不受影响。

**巡视重访** `revisit(frames)`：存在 t1 < t2，同时满足：

1. t1、t2 都在给定帧集合内，且两帧都有 L_{f*} = 1；
2. |p(t1) − p(t2)| ≤ 30 m；
3. 在 [t1, t2] 内，max |p(t) − p(t1)| ≥ 150 m；
4. 两时刻速度都 ≥ 0.5 m/s，且航向夹角 ≤ 45° 或 ≥ 135°；
5. [t1, t2] 内各位置绕 c 的方位覆盖 ≥ 120°。方位覆盖 = 360° 减去排序后方位角的最大圆周间隙。

返回 `t_confirm` 最早的合格点对（取最小 t2；t2 相同时取最小 t1）。

实现要求：不得对全部帧对做两两比较。先用空间网格或 KD 树找出 30 m 内的候选点对，再用时间差下限 t2 − t1 ≥ 2 × (150 − 30) / v_max 过滤（v_max 取该轨迹的最大速度）。

**区域覆盖**：沿用现有理想观察模型和网格。有效帧要求：位于声明扫描区域内、速度 ≥ 0.5 m/s、L_{f*} = 1、不在限制区内。组内成员的足迹取并集，覆盖率 ≥ 0.80。

### 7.3 角色判据（单机）

所有角色**全程**遵守禁入：对其他设施 L ≤ 1；对 f*，L 不超过 `exclusion_max_layer[角色]`。

| 角色 | 正判据 | 负判据（只在 W_i 内检查） | 终态 | 核心事件 `t_s` |
|---|---|---|---|---|
| 过境 | L_{f*} ≥ 1 的帧构成恰好一个连续区间 | 无驻留；无巡视重访 | 末帧 L_{f*} = 0 | 首次 L_{f*} ≥ 1，`enter_warning_zone` |
| 区域搜索 | 存在有效观察帧；组覆盖率 ≥ 0.80 | 无巡视重访 | 末帧 L_{f*} = 0 | 首个有效观察帧，`scan_start` |
| 抵近观察 | 存在驻留，窗口内各帧 L_{f*} = 1 | 无巡视重访 | 末帧 L_{f*} = 0 | 首个合格驻留窗口起点，`observation_point_arrival` |
| 监视 | W_i 内存在巡视重访 | 无 | 末帧 L_{f*} = 0 | 首次 L_{f*} ≥ 1，`enter_warning_zone`（勘误后） |
| 佯动 | 出现 L_{f*} = 2，且 L_{f*} ≥ 2 的帧构成恰好一个连续区间 | 无 | 末帧 L_{f*} = 0 | 首次 L_{f*} ≥ 2，`enter_alert_zone` |
| 突击 | 出现 L_{f*} = 3，且 min d_{f*} ≤ 50 m | 无 | 不要求 | 首次 L_{f*} = 3，`enter_protected_zone` |
| 中止（主编组） | 进入目标警戒区；转折后离开目标预警区 | 全程未进禁飞区 | 末帧 L_{f*} = 0 | 无（按定义缺失） |

- 截断前缀沿用现有 `measurable` / `bounded` 语义：正判据观察到即为真；负判据一旦出现即为否；观察完整前尚未确定的为未知。
- 超时运行的观察完整性**沿用现有代码**（`completed` 与 `timeout` 都视为完整观察），不要改。

### 7.4 降为诊断字段（照常输出，不进入 `result.conditions`）

过境弦长、进出方位差、区内最长低速、累计转向；作业段折返次数（某时刻航向与 20 s 前航向夹角 ≥ 135°，两时刻速度都 ≥ 0.5 m/s，连续满足的帧合并计 1 次）；监视圈数与组重访间隔；佯动深入比例与撤离单调性统计；突击禁飞区深度与到轮廓最小距离；终点最近距离与悬停时长；撤离点到达；条带端点顺序；驻留总时长；中止的到达撤离点。
