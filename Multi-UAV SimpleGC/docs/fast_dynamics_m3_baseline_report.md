## 2. 指标口径与本轮诊断修复

- 每个 v0.6 参考运行使用自己的 `clock_models.json`，沿用 T1 的 CommonTimeAxis：自然编号最小且有效、覆盖起点的参考机，分段主机/源钟关系求逆，减去源钟起点；不外推、不统一乘0.975。r2主机/仿真总时长比中位数 **1.023954**，范围 **1.017268–1.054164**；本次轨迹行因钟支持域不足丢弃0行。被动钟残差不代表绝对同步精度。
- 成功/条件比较保留历史 SITL 判定与 fastsim 实测判定，不用参考标签赋值。运动槽位取公共事实计算实际使用的 `observed_pattern`：SITL 用其导出采样，fastsim 用内部 support。首要一致率以 **SITL 可识别的固定任务集合**为分母，候选 `unclear` 不算匹配；双方未知另列。不能只报“双边已知100%”。
- 总时长为空中任务窗口，不含 SITL 起降。阶段时长为各机最早 release 至最晚窗口 end，保留真实错峰与等待。相对误差为 (fast−SITL)/SITL；表中给绝对值分布，原始带符号值也保存。超时运行600秒保留在全量诊断中，是截断运行，不当作正常完成时长。
- 横向偏差使用同 phase/agent/有序航段/展开圈次上的法向位置差，0.5m弧长网格；不跨圈找全局最近点。保留回退/缺测不匹配，报告匹配长度。真值最小机间距用共同仿真时刻的三维分段线性相对运动最小值，不逐机时间扭曲。
- 速度为水平位置1秒中心差分；巡航取主任务航段中间20%–80%，转弯角≥15°处，在实际航点见证±1秒内取最低差分速度，再在每任务内对各弯取中位数。它是固定窗口指标，**不是瞬时速度极值**。94条直线通过没有转弯指标，属不适用，不填0。全部任务巡航指标可用，转弯指标188条。
- 指标先逐任务，再逐family等权汇总；不能把轨迹帧当独立样本。完整分布含 n、中位数、p90、p95、最小、最大；报告表为“中位数 / p95 / 最大”。

## 5. 两类前置问题与动力学残差

**槽位采样密度敏感性**：15条扫描的公共事实链将内部support作为输入，而 `_straight_evidence` 忽略相邻位移≤0.05m的段。在2–2.5m/s的约50Hz支持采样下，这会丢失连续直线证据；SITL约10Hz不会以同样方式丢失。只读诊断把同一fast飞行的公开10Hz CSV交给同一分类器，15/15恢复parallel_strips，未改参数或阈值。证据 `slot_sampling_diagnostic.json`。这不是230°累计转向降级所致，也不能靠提高任务巡航速度来“修好”。正式主基线仍保留15个未匹配；统一几何取样口径属于后续待批准的数据链修复，本轮没有修改事实或描述器。

**短段航点见证停滞**：`patrol_0070_v00`（3机）SITL239.677秒完成；fast到600秒仍超时，数值、速度/加速度/jerk与间距检查正常。uav_02/03约217.16秒done，uav_01已停在规划终点，但仅见证到第5/10个航点；该巡逻路线最短段0.1026626m，最后一次见证在218.377007秒。证据 `outlier_diagnostics.json`。这是过点推进/见证一致性问题，不能简单加长超时，也不能从分母删除；本轮只登记，不越过第5步修复跟踪器。

**动力学残差**：正常运行的转弯速度普遍偏低，扫描/巡逻阶段偏长；当前转弯速度上限含 `corner_cut_max_m/(velocity_response_time_s+response_time_s)`，默认上界约0.238m/s，同时受曲率及jerk约束。不能只放大最大加速度。建议先处理上述两个前置项，再按[一页调参方案与数值标准](fast_dynamics_m3_tuning_proposal.md)执行四参数有界搜索。当前模型不满足该待批准方案中的完成率、槽位、部分时长和转弯速度标准，**不冻结参数**。
