# v0.6 新 pilot 与正式生产：用户手动运行命令

本文件属于 [正式计划](v06_formal_plan.md) 第 3.4 节的交付。**暂停 A 只交付代码、离线证据和文档；本轮不 prepare、不启动任何批次。** 用户以后明确指示准备 pilot 后，才能执行准备命令；仿真始终由用户在自己的 PowerShell 7 前台终端启动，助手只做准备和事后分析。

最终离线任务清单共有 **900 条目，600 个规划通过、300 个 `planning_rejected`**。证据位于 `SwarmData/v06_pauseA_20261008/planning_final/planning_report.json`，查看 `accepted_tasks`、`task_entries` 和 `groups[].rejected`。当前不能直接准备或启动 pilot，必须先在暂停 A 由用户人工审查飞法可行性。不得自行改飞法、换种子或删掉失败项凑数。存在拒绝项时 `prepare` 明确拒绝，保留 `bundle/` 和 `prepare_error.json`，不生成可运行的 `plan.json/control.json`。以下命令用于未来复核后的操作，CI 通过不等于完整清单已经可行或 pilot 实测已经通过。

| 项目 | 新 pilot | 正式生产 |
| --- | --- | --- |
| profile | `generation_profiles/tri_intent_v06_pilot.json` | `generation_profiles/tri_intent_v06_production.json` |
| 主种子 | `2026100811` | `2026100812` |
| 规模 | 10 family／30 任务，3 意图各 10 | 300 family／900 任务，3 意图各 300 |
| 标签门禁 | 远端 `v0.6-pauseA` | 暂停 B 复核、阈值冻结后的远端 `v0.6-pilot` |
| 尝试预算 | 暂定 60，留待下一阶段准备前确认 | 990 |
| 并行 | 2 路，端口 19100–19199／19200–19299 | 同左 |
| 用途 | 标记 pilot，不进入训练数据 | 复核冻结后用于算法线 |
| 存储预算 | 每尝试 1 GiB＋导出 10 GiB 仅为待确认的 pilot 准备估算 | 新 pilot 实测全批占用／实际运行数，再乘 1.5；另计导出预留 |

这些种子与 DR130 的 `2026100205` 及旧两路 pilot 的 `2026100701` 不同。这里的批次尚未准备，命令不引用旧 `v06_pilot20_20261007_seed2026100701`。若未来复核必须调整配置或批次标识，先更新文档、提交并完成 CI；不得改写已有批次。

所有变更直接在 `main` 完成。下列块核对：工作区干净、HEAD 等于远端 main、所需远端标签指向同一提交、该提交最新一次 push CI 成功。CI 通过只证明离线检查；仍须完成当前阶段的用户复核。批次运行期间不修改仓库文件、不切分支、不 pull，记录用 `-B` 防止生成字节码缓存。命令只读取远端引用，不自动 fetch 或 checkout。

CI 查询使用 PowerShell `Invoke-RestMethod` 访问 GitHub 公共 REST API，不依赖本机 `gh`。请求限定工作流 `unit-tests.yml`、当前 HEAD、main 分支及 push 事件，并再核对返回字段，取最新运行及重试的结论；网络或限流导致无法核验时不能跳过。每块自包含，默认 `$operation='status'` 只查询一次；按当前阶段改成 `prepare`、`run`、`resume` 或 `finalize` 后执行整块。每次仅做选定的一步，prepare 后不会自动起飞，run 后不会自动 finalize。

## 新 pilot：30 任务

仅在暂停 A 复核及后续用户指令允许准备后使用。尝试预算与磁盘估算须在准备前确认；它们没有改动既有重试规则，只有确认的起飞前故障允许重试一次，失败记录保留。

```powershell
$ErrorActionPreference = 'Stop'
if ($PSVersionTable.PSVersion.Major -lt 7) { throw '请使用 PowerShell 7 (pwsh)。' }
$PSNativeCommandUseErrorActionPreference = $false
$operation = 'status' # 改成 prepare、run、resume、status 或 finalize；每次只执行一种操作。
$batchId = 'v06_pilot30_seed2026100811'
$requiredTag = 'v0.6-pauseA'
$profile = 'generation_profiles/tri_intent_v06_pilot.json'
$masterSeed = 2026100811
$familyCount = 10
$expectedTasks = 30
$attemptBudget = 60 # 暂定待下一阶段确认；不超过每任务一次起飞前重试。
$purpose = 'pilot'
$trainingData = $false
$repo = 'F:\CASIA\Drone Swarm Situational Awareness Algorithm\Simulation-dev'
$project = Join-Path $repo 'Multi-UAV SimpleGC'
$env:SIM_DATA_ROOT = 'F:\CASIA\Drone Swarm Situational Awareness Algorithm\SwarmData'
$env:PYTHONDONTWRITEBYTECODE = '1'
$condaExe = 'C:\Users\shy\anaconda3\Scripts\conda.exe'
Set-Location -LiteralPath $project
$projectEnv = (Get-Content -LiteralPath '.conda-env' -Raw -Encoding utf8).Trim()
if ($projectEnv -ne 'llm') { throw '项目环境已变；先核对 .conda-env，不自动切换环境。' }
if (@('prepare','run','resume','status','finalize') -notcontains $operation) { throw '未知操作。' }
$batchDir = Join-Path $env:SIM_DATA_ROOT ('parallel_batch\' + $batchId)

function Invoke-BatchOffline {
    param([string[]]$BatchArgs)
    & $condaExe run -n $projectEnv --no-capture-output python -B scripts/run_parallel_batch.py @BatchArgs
    if ($LASTEXITCODE -ne 0) { throw '命令未成功；保留错误及全部证据，不启动后续操作。' }
}

# status 只读一次；其余操作先核对当前 main、远端标签和该提交最新一次 push CI。
if ($operation -ne 'status') {
    $branch = (git -C $repo branch --show-current).Trim()
    if ($LASTEXITCODE -ne 0 -or $branch -ne 'main') { throw '要求 main 分支。' }
    $dirty = @(git -C $repo status --porcelain)
    if ($LASTEXITCODE -ne 0 -or $dirty.Count -ne 0) { throw '工作区有改动；先处理并完成 CI，不能在批次期间编辑。' }
    $head = (git -C $repo rev-parse HEAD).Trim()
    if ($LASTEXITCODE -ne 0) { throw '读取 HEAD 失败。' }
    $remoteRows = @(git -C $repo ls-remote origin 'refs/heads/main' "refs/tags/$requiredTag" "refs/tags/$requiredTag^{}")
    if ($LASTEXITCODE -ne 0) { throw '读取远端 main/标签失败。' }
    $refs = @{}
    foreach ($row in $remoteRows) { $parts = $row -split '\s+', 2; $refs[$parts[1]] = $parts[0] }
    $tagRef = "refs/tags/$requiredTag"
    $tagHead = if ($refs.ContainsKey("$tagRef^{}")) { $refs["$tagRef^{}"] } else { $refs[$tagRef] }
    if ($refs['refs/heads/main'] -ne $head -or $tagHead -ne $head) { throw 'HEAD 必须同时等于远端 main 和所需标签；不要在运行中 checkout/pull。' }
    $ciApi = 'https://api.github.com/repos/shy-UCAS/swarm-task-sim/actions/workflows/unit-tests.yml/runs?branch=main&event=push&head_sha=' + [Uri]::EscapeDataString($head) + '&per_page=100'
    $apiHeaders = @{Accept='application/vnd.github+json'; 'X-GitHub-Api-Version'='2022-11-28'; 'User-Agent'='swarm-task-sim-ci-check'}
    try { $ciResponse = Invoke-RestMethod -Method Get -Uri $ciApi -Headers $apiHeaders }
    catch { throw ('无法通过 GitHub 公共 REST API 核验 CI（网络、限流或访问错误）；不能跳过：' + $_.Exception.Message) }
    $ci = @($ciResponse.workflow_runs | Where-Object {
        $_.head_sha -eq $head -and $_.event -eq 'push' -and $_.head_branch -eq 'main'
    } | Sort-Object -Property @{Expression='run_number';Descending=$true}, @{Expression='run_attempt';Descending=$true} | Select-Object -First 1)
    if ($ci.Count -ne 1 -or $ci[0].head_sha -ne $head -or $ci[0].status -ne 'completed' -or $ci[0].conclusion -ne 'success') { throw '当前 HEAD 的最新一次 main push CI 未成功。' }
    Write-Host ('已核验远端 CI：' + $ci[0].html_url)
}

if ($operation -eq 'prepare') {
    if (Test-Path -LiteralPath $batchDir) { throw '批次目录已存在；禁止覆盖或重新 prepare。' }
    $profileData = Get-Content -LiteralPath $profile -Raw -Encoding utf8 | ConvertFrom-Json
    if ($profileData.master_seed -ne $masterSeed -or $profileData.base_scene_count -ne $familyCount -or @($profileData.missions).Count -ne 3) { throw 'profile 的种子/规模与本命令不一致。' }
    $bytesPerAttempt = [long]1GB # 仅新 pilot 的暂定准备估算，不是实测值。
    $exportReserveBytes = [long]10GB # 同样需在未来 prepare 前确认。
    Invoke-BatchOffline -BatchArgs @('prepare','--batch-id',$batchId,'--profile',$profile,'--shards','2',
        '--max-attempts',"$attemptBudget",'--storage-bytes-per-attempt',"$bytesPerAttempt",
        '--export-reserve-bytes',"$exportReserveBytes",'--split-salt','simplegc-v02')
    $plan = Get-Content -LiteralPath (Join-Path $batchDir 'plan.json') -Raw -Encoding utf8 | ConvertFrom-Json
    if (@($plan.tasks).Count -ne $expectedTasks -or $plan.protocol.semantic_validation_version -ne 'multi_intent_validation_v06') { throw '准备结果规模或协议不符，不启动。' }
    [ordered]@{purpose=$purpose; training_data=$trainingData; source_commit=$head; source_tag=$requiredTag;
        source_ci=$ci[0].html_url; master_seed=$masterSeed; families=$familyCount; tasks=$expectedTasks;
        storage_bytes_per_attempt=$bytesPerAttempt; export_reserve_bytes=$exportReserveBytes} |
        ConvertTo-Json | Set-Content -LiteralPath (Join-Path $batchDir 'batch_purpose.json') -Encoding utf8
    Write-Host ('准备完成，已启动仿真数为 0。核对后由用户单独执行 run：' + $batchDir)
} else {
    if (-not (Test-Path -LiteralPath (Join-Path $batchDir 'plan.json'))) { throw '批次尚未成功准备。' }
    $plan = Get-Content -LiteralPath (Join-Path $batchDir 'plan.json') -Raw -Encoding utf8 | ConvertFrom-Json
    if (@($plan.tasks).Count -ne $expectedTasks -or $plan.protocol.semantic_validation_version -ne 'multi_intent_validation_v06') { throw '批次身份/规模/协议不符。' }
    $control = Get-Content -LiteralPath (Join-Path $batchDir 'control.json') -Raw -Encoding utf8 | ConvertFrom-Json
    if ($operation -eq 'status') {
        Invoke-BatchOffline -BatchArgs @('status','--batch-id',$batchId)
    } elseif ($operation -eq 'finalize') {
        if (-not $control.completed -or $control.finalized -or $control.stopped_reason) { throw '仅允许全部完成、未停止、尚未收尾的批次 finalize 一次。' }
        Invoke-BatchOffline -BatchArgs @('finalize','--batch-id',$batchId)
        $report = Get-Content -LiteralPath (Join-Path $batchDir 'final_report.json') -Raw -Encoding utf8 | ConvertFrom-Json
        if ($report.total -ne $expectedTasks -or -not $report.description_check.consistency_pass) { throw '收尾报告不满足规模/一致性要求；保留证据。' }
        Write-Host ('收尾报告：' + (Join-Path $batchDir 'final_report.json'))
    } else {
        if ($control.stopped_reason -or $control.finalized -or $control.completed) { throw '规则停止、已完成或已收尾的批次不执行 run/resume。' }
        if ($operation -eq 'run' -and (@($control.attempts).Count -ne 0 -or $control.paused)) { throw '已有尝试或暂停状态只能使用显式 resume。' }
        if ($operation -eq 'resume' -and -not $control.paused) { throw '此操作块仅续跑已正常排空的人工暂停；异常退出交由事后分析。' }
        # 交互 run/resume 延用旧 pilot 文档：直接前台 Python 收到 Ctrl+C。
        (& $condaExe 'shell.powershell' 'hook') | Out-String | Invoke-Expression
        conda activate $projectEnv
        if ($env:CONDA_DEFAULT_ENV -ne $projectEnv) { throw '项目 Conda 环境未成功激活。' }
        python -B -c 'import os,sys; from pathlib import Path; assert Path(sys.prefix).resolve()==Path(os.environ["CONDA_PREFIX"]).resolve(); print(sys.executable)'
        if ($LASTEXITCODE -ne 0) { throw 'Python 解释器不属于已激活的项目环境。' }
        $runArgs = @('run','--batch-id',$batchId)
        if ($operation -eq 'resume') { $runArgs += '--resume' }
        $logPath = Join-Path $batchDir ('console_' + [guid]::NewGuid().ToString('N') + '.log')
        Start-Transcript -LiteralPath $logPath -NoClobber
        try {
            python -u -B scripts/run_parallel_batch.py @runArgs
            if ($LASTEXITCODE -ne 0) { throw '控制器非零退出；保留 stop_report 和全部尝试，不自动重跑。' }
            $after = Get-Content -LiteralPath (Join-Path $batchDir 'control.json') -Raw -Encoding utf8 | ConvertFrom-Json
            Write-Host ('completed=' + $after.completed + '; paused=' + $after.paused + '; stopped_reason=' + $after.stopped_reason)
            Write-Host '暂停则下次显式 resume；全部完成后单独 finalize。本块不会自动收尾。'
        } finally { Stop-Transcript }
    }
}
```

## 正式生产：900 任务

仅在新 pilot 事后复核和阈值冻结完成后使用。标签 `v0.6-production` 是生产完成及复核后的标记，不能提前用于生产启动；启动依据是 `v0.6-pilot`。下面的 prepare 从新 pilot 实测目录自动计算空间，不能用旧 1 GiB／次估算替代；显示实际运行分母，所有重试占用仍包含在批次总大小中。

```powershell
$ErrorActionPreference = 'Stop'
if ($PSVersionTable.PSVersion.Major -lt 7) { throw '请使用 PowerShell 7 (pwsh)。' }
$PSNativeCommandUseErrorActionPreference = $false
$operation = 'status' # 改成 prepare、run、resume、status 或 finalize；每次只执行一种操作。
$batchId = 'v06_production900_seed2026100812'
$requiredTag = 'v0.6-pilot' # 暂停 B 复核及阈值冻结后的 CI 通过标签。
$profile = 'generation_profiles/tri_intent_v06_production.json'

}

    $branch = (git -C $repo branch --show-current).Trim()
    if ($LASTEXITCODE -ne 0 -or $branch -ne 'main') { throw '要求 main 分支。' }

    $head = (git -C $repo rev-parse HEAD).Trim()
    if ($LASTEXITCODE -ne 0) { throw '读取 HEAD 失败。' }
    $remoteRows = @(git -C $repo ls-remote origin 'refs/heads/main' "refs/tags/$requiredTag" "refs/tags/$requiredTag^{}")
    if ($LASTEXITCODE -ne 0) { throw '读取远端 main/标签失败。' }
    $refs = @{}
    foreach ($row in $remoteRows) { $parts = $row -split '\s+', 2; $refs[$parts[1]] = $parts[0] }
    $tagRef = "refs/tags/$requiredTag"
    $tagHead = if ($refs.ContainsKey("$tagRef^{}")) { $refs["$tagRef^{}"] } else { $refs[$tagRef] }
    if ($refs['refs/heads/main'] -ne $head -or $tagHead -ne $head) { throw 'HEAD 必须同时等于远端 main 和所需标签；不要在运行中 checkout/pull。' }

    catch { throw ('无法通过 GitHub 公共 REST API 核验 CI（网络、限流或访问错误）；不能跳过：' + $_.Exception.Message) }
    $ci = @($ciResponse.workflow_runs | Where-Object {
        $_.head_sha -eq $head -and $_.event -eq 'push' -and $_.head_branch -eq 'main'
    } | Sort-Object -Property @{Expression='run_number';Descending=$true}, @{Expression='run_attempt';Descending=$true} | Select-Object -First 1)

    Write-Host ('已核验远端 CI：' + $ci[0].html_url)
}

    if (Test-Path -LiteralPath $batchDir) { throw '批次目录已存在；禁止覆盖或重新 prepare。' }

    $pilotReport = Get-Content -LiteralPath (Join-Path $pilotDir 'final_report.json') -Raw -Encoding utf8 | ConvertFrom-Json

    $exportReserveBytes = [long][math]::Max(1, [math]::Ceiling(1.5 * $pilotExportBytes * $expectedTasks / 30))
    Write-Host ("pilot 总字节={0}，实际运行={1}，每尝试预留={2}，导出预留={3}" -f $pilotBytes,$actualRuns.Count,$bytesPerAttempt,$exportReserveBytes)

        '--export-reserve-bytes',"$exportReserveBytes",'--split-salt','simplegc-v02')

    if (@($plan.tasks).Count -ne $expectedTasks -or $plan.protocol.semantic_validation_version -ne 'multi_intent_validation_v06') { throw '准备结果规模或协议不符，不启动。' }
    [ordered]@{purpose=$purpose; training_data=$trainingData; source_commit=$head; source_tag=$requiredTag;
        source_ci=$ci[0].html_url; master_seed=$masterSeed; families=$familyCount; tasks=$expectedTasks;
        storage_bytes_per_attempt=$bytesPerAttempt; export_reserve_bytes=$exportReserveBytes} |
        ConvertTo-Json | Set-Content -LiteralPath (Join-Path $batchDir 'batch_purpose.json') -Encoding utf8
    Write-Host ('准备完成，已启动仿真数为 0。核对后由用户单独执行 run：' + $batchDir)
} else {
    if (-not (Test-Path -LiteralPath (Join-Path $batchDir 'plan.json'))) { throw '批次尚未成功准备。' }
    $plan = Get-Content -LiteralPath (Join-Path $batchDir 'plan.json') -Raw -Encoding utf8 | ConvertFrom-Json
    if (@($plan.tasks).Count -ne $expectedTasks -or $plan.protocol.semantic_validation_version -ne 'multi_intent_validation_v06') { throw '批次身份/规模/协议不符。' }
    $control = Get-Content -LiteralPath (Join-Path $batchDir 'control.json') -Raw -Encoding utf8 | ConvertFrom-Json
    if ($operation -eq 'status') {
        Invoke-BatchOffline -BatchArgs @('status','--batch-id',$batchId)
    } elseif ($operation -eq 'finalize') {
        if (-not $control.completed -or $control.finalized -or $control.stopped_reason) { throw '仅允许全部完成、未停止、尚未收尾的批次 finalize 一次。' }
        Invoke-BatchOffline -BatchArgs @('finalize','--batch-id',$batchId)
        $report = Get-Content -LiteralPath (Join-Path $batchDir 'final_report.json') -Raw -Encoding utf8 | ConvertFrom-Json
        if ($report.total -ne $expectedTasks -or -not $report.description_check.consistency_pass) { throw '收尾报告不满足规模/一致性要求；保留证据。' }
        Write-Host ('收尾报告：' + (Join-Path $batchDir 'final_report.json'))
    } else {
        if ($control.stopped_reason -or $control.finalized -or $control.completed) { throw '规则停止、已完成或已收尾的批次不执行 run/resume。' }
        if ($operation -eq 'run' -and (@($control.attempts).Count -ne 0 -or $control.paused)) { throw '已有尝试或暂停状态只能使用显式 resume。' }
        if ($operation -eq 'resume' -and -not $control.paused) { throw '此操作块仅续跑已正常排空的人工暂停；异常退出交由事后分析。' }
        # 交互 run/resume 延用旧 pilot 文档：直接前台 Python 收到 Ctrl+C。
        (& $condaExe 'shell.powershell' 'hook') | Out-String | Invoke-Expression
        conda activate $projectEnv
        if ($env:CONDA_DEFAULT_ENV -ne $projectEnv) { throw '项目 Conda 环境未成功激活。' }
        python -B -c 'import os,sys; from pathlib import Path; assert Path(sys.prefix).resolve()==Path(os.environ["CONDA_PREFIX"]).resolve(); print(sys.executable)'
        if ($LASTEXITCODE -ne 0) { throw 'Python 解释器不属于已激活的项目环境。' }
        $runArgs = @('run','--batch-id',$batchId)
        if ($operation -eq 'resume') { $runArgs += '--resume' }
        $logPath = Join-Path $batchDir ('console_' + [guid]::NewGuid().ToString('N') + '.log')
        Start-Transcript -LiteralPath $logPath -NoClobber
        try {
            python -u -B scripts/run_parallel_batch.py @runArgs
            if ($LASTEXITCODE -ne 0) { throw '控制器非零退出；保留 stop_report 和全部尝试，不自动重跑。' }
            $after = Get-Content -LiteralPath (Join-Path $batchDir 'control.json') -Raw -Encoding utf8 | ConvertFrom-Json
            Write-Host ('completed=' + $after.completed + '; paused=' + $after.paused + '; stopped_reason=' + $after.stopped_reason)
            Write-Host '暂停则下次显式 resume；全部完成后单独 finalize。本块不会自动收尾。'
        } finally { Stop-Transcript }
    }
}
```

## 人工暂停、规则停止与收尾

在运行窗口按一次 Ctrl+C 后保持窗口打开，等待控制器停止派发、在飞任务正常降落／清理／分析并退出。重复 Ctrl+C 仍只请求暂停。正常排空后台账为 `paused=true`、`stopped_reason=null`，已经启动的尝试为 `finished`；如果最后一批恰好全部完成，则直接为 `completed=true`。下次执行同一块并设 `$operation='resume'`，原预算、尝试身份及滚动窗口继续计算，不重复或遗漏任务。不要关闭终端或按进程名终止进程。

run/resume 使用旧 pilot 文档的已激活 `llm` 前台 Python 方式，让 Ctrl+C 直接进入控制器；先读取 `.conda-env` 并核对 `CONDA_DEFAULT_ENV`、`sys.executable` 和 `sys.prefix`，不切换项目环境。prepare/status/finalize 用 `conda run`。这条交互信号路径本轮只有离线合成测试，尚未做真实飞行中的中断试验。

规则停止仍按正式计划第 6 节执行，`stopped_reason` 不可清除，`--resume` 明确拒绝；不手改台账、不补飞洗掉失败。主机崩溃或窗口被关闭造成的未知尝试也不能当作正常人工暂停；保留目录交由事后分析。一次 status 是用户手动只读快照，本文件没有后台监视器或自动续跑。

全部任务完成后，单独执行 `finalize`，统一合并、导出、审计、生成描述并加载核验。成功标准为 `completed=true`、`finalized=true`、`stopped_reason=null`，以及 `final_report.json.total` 为 30 或 900、描述一致性通过。质量不合格运行仍保留；数字按意图／飞法报告。family 跨划分泄漏拒绝收尾，审计文件和停止报告保留。

新 pilot 收尾后停在暂停 B 等复核；生产收尾后停在暂停 C 等复核和冻结。任何失败的 prepare／finalize 均保存原目录和错误，不能覆盖已有证据反复重建。旧 `Simulation` 归档始终只读。
