## 人工暂停、规则停止与收尾

新 30 任务 pilot 必须安排一次真实人工暂停／续跑检查：用户可在另一 PowerShell 7 窗口手动执行下方一次 `progress`，约 15/30 个不同任务已有最终尝试时，回到运行前台窗口按一次 Ctrl+C。这里只给出手动检查命令，不自动轮询、不按计时器中断。允许当时在飞的 worker 继续完成，因此实际暂停的已完成数可能略高于 15；报告保留实际分母。

在运行窗口按一次 Ctrl+C 后保持窗口打开，等待控制器停止派发、在飞任务正常降落／清理／分析并退出。重复 Ctrl+C 仍只请求暂停。正常排空后台账为 `paused=true`、`stopped_reason=null`，已经启动的尝试为 `finished`；如果最后一批恰好全部完成，则直接为 `completed=true`。下次执行同一块并设 `$operation='resume'`，原预算、尝试身份及滚动窗口继续计算，不重复或遗漏任务。不要关闭终端或按进程名终止进程。

前台命令退出后，把下方 `$checkOperation` 改成 `checkpoint` 执行整块，核对人工暂停及排空状态并保存原台账副本；随后执行上方 pilot 完整命令块、设 `$operation='resume'`，该操作实际调用 `run --resume`。续跑全部完成后、首次 finalize 前，再以 `verify` 执行下方整块，核对任务覆盖、尝试合法性、暂停前台账前缀和预算连续性；成功后保存 `manual_pause_resume/verification.json`。最后将上方 pilot 块设为 `$operation='finalize'` 执行。最终状态查询会调用控制器的台账校验，按完整完成顺序重放滚动窗口，不能以清空窗口实现续跑。副本仅作事后核验，绝不能用它覆盖 `control.json`。
