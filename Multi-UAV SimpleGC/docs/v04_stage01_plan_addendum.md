## 1. 已确认的入口与本轮暂停点

用户接受 `exact_duplicate_drop_v1` 作为 WP-S 离线复核规则，明确确认 WP-S GO。独立记录为 [v04_spike_go_confirmation.json](v04_spike_go_confirmation.json)，保存用户确认原文、[复核报告](v04_spike_review_01.md)与复算汇总的 SHA256。原 `v04_spike_summary.json`、两份 UNKNOWN 指标报告及运行目录不更新。

本轮授权仅为 **WP-G：G1 → G2 → G3 → G4**，使用纯逻辑、合成证据、mock 和既有数据离线复算。G4 完成后提交里程碑报告并暂停，等待用户确认，随后才能开始 WP-E。不能因编译接口已具备 v3 结构而提前运行 v3 SITL。

## 2. G3 新增观测处理合同，E3 再接线

v3 固定采用 `exact_duplicate_drop_v1` 与 `full_stream_strict_v1`。源时间相同且完整消息内容相同的包保留首次记录，余包只从指标输入中排除；保留 raw、行号、分类和计数。同时间内容冲突、源时间回退、非法时间及接收逆序仍使相关整条流失效；SYSTEM_TIME 异常使时钟模型不可用。

G3 实现独立接口、版本字段和测试。原始输入按全流审计，**不实现按窗口分层判定资格，不裁掉窗口外异常**。v1/v2 的 ObservationStream、时钟拟合器及默认数值质量策略保持原样，旧任务不进入新预处理器。E3 再接入 v3 分析流水线。

| 字段 | G3 接口版本 |
| --- | --- |
| observation_processing_version | v3_observation_v1 |
| duplicate_policy_version | exact_duplicate_drop_v1 |
| timeline_policy_version | full_stream_strict_v1 |
| clock_model_version | passive_system_time_piecewise_v1 |

分析 manifest、quality 及相关观测/时钟审计产物记录这些字段，跨产物不一致必须拒绝。时钟在去重后按原有训练/验证拆分拟合；不能将去重前的模型冒充新口径。G3 测试合同，E3 负责实际生成和传播产物。`invalid_intervals` 仅保存按飞机划分的无效观测、异常标记及采样缺口，不定义窗口资格函数。

## 3. v3 运行证据要求：纳入 E2

每次 v3 生产运行都进行参数读回，不能仅在 WP-S 读取一次后复用。起飞前完成读取，将每机完整性、参数表、WPNAV_*、超时/缺项信息和读取状态写入本次运行元数据或受其哈希绑定的附件；失败不能标成完整。

每条参数请求新增 TX 记录，至少包括：请求类型（PARAM_REQUEST_LIST / PARAM_REQUEST_READ）、首次/重发/补读分类、目标 sysid/component、缺项索引、请求关联 ID、发送前及发送后的主机单调时间、成功/异常状态。发送时刻不能用首个响应时间代替，仍复用单一 MAVLink 接收线程。读取只读，不自动修改飞控参数。

每次 v3 运行记录固件 SHA256、版本字符串及来源、参数模板 SHA256。AUTOPILOT_VERSION 没有回应时，可以明确标注二进制元数据来源，不能写成运行时读回成功。

**固件文件或参数模板变化时，必须重新执行 WP-S，并获得新的 GO 确认后才能用新组合进行 v3 生产运行。** E2 应比较本次指纹与已确认 WP-S 的固件/模板指纹，不匹配时在起飞前阻止继续。实际读回参数的变化也必须显式记录和解释，不能用文件哈希掩盖运行配置差异。

本轮 G 阶段不接入生产飞行流程；v3 `run` 明确拒绝并提示等待 E2，确保尚未实现的记录要求不会被绕过。v1/v2 运行行为不变。

## 4. 执行与报告补充

`lane_end_overshoot_m` 默认保持 0，本轮不以外延改变几何。原计划关于非零外延的实测依据、观察半径及世界边界限制继续有效，执行实现留 WP-E。

原计划 7.5 的 `arrival_s` 定义保持不变：从终点到点事件向后搜索，首次同时满足终点距离容差与 \(\lVert v_{xy}\rVert \le 0.3\,\mathrm{m/s}\) 的时刻；直到阶段结束仍不满足时，取后续范围内最近距离时刻；双通道分别计算并记录来源。WP-S 最近距离诊断不能代替该定义。SIM 无直接速度字段的事实必须保留，采用派生速度时明确版本与限制。

V03、V04 和试生产 V06 报告增加中间航点 2 m 邻域内最低水平过点速度分布，按所属扫描线长度分组，给出有效点数/总点数、未知数、单位、速度通道和处理版本。扫描线长度指完整扫描线的规划长度，不能用换线段或进近距离代替。G4 提供诊断与分组接口，V 阶段填入真实运行测量；缺测不能写成 0。
