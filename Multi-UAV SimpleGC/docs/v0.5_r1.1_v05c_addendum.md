# v0.5 修订版 r1.1 续补：v05c 固定初始航向

本续补依据用户在 [v05b 验证停止报告](v0.5b_r1.1_validation_stop_01.md)后的决定。修订版 r1、[r1.1 采样与选例补充](v0.5_r1.1_addendum.md)的其余规则、停止条件和暂停 1 边界继续有效。v05b 失败的 VP1 保持原判并计入验证预算；原 v05、v05b profile、DR、诊断、停止报告和运行目录均为历史证据，不覆盖。以下门禁在 v05c DR 前固定，不随结果调整采样范围、种子或候选上限。

## 采样与 profile

`random_spawn_v2` 增加可选 `heading_policy`。缺失时仍逐机均匀采样航向，保持 v05b 行为；`fixed_zero` 时逐机照原顺序抽取航向随机数、丢弃，再将初始航向设为 \(0^\circ\)。其他随机抽取调用及顺序不变。新建 `generation_profiles/dual_intent_v05c.json`，除 `scene_sampler.params.heading_policy="fixed_zero"` 外与 `dual_intent_v05b.json` 完全相同；分别记录原始文件 SHA256 和规范化 profile 指纹。

现有 `wp_s_parameter_comparison_v2` 不变。v05b 三机 `SIM_PLD_YAW` 的读回值与 `--home` 初始航向向零取整后的数值对应，支持两者相关的推断，但尚未独立证实固件内部规则。v0.5 的 v05c 运行仅支持 \(0^\circ\) 初始航向；任何未解释的参数差异仍须在起飞前停止。将来若要支持随机初始航向，须先取得大于 \(180^\circ\) 航向下 `SIM_PLD_YAW` 取值的实测证据，再制定与实际航向绑定的版本化比较规则，不得简单豁免该参数。

## DR 与逐项等价门禁

在独立目录重新生成 v05c 的 130 个基础场景，先核对 profile 的文件/规范化指纹及全部附件哈希。沿用 v05b 预注册 DR 门禁：联合可行候选数占全部候选抽取数至少 30%；130/130 个基础场景被接受，\(N=2,3,4\) 的接受数分别严格为 44、43、43；接受集的侦察 observe 阶段按实际条带宽 \(W\) 和扫描线中心距 \(\delta\) 核对 \(d=W-\delta\)，不存在 \(d<7\,\mathrm{m}\)，并与完整时间感知间距检查交叉核对。报告候选与接受集的机数、进场方向、剖分轴、旋转角、区域宽高及速度分布，以及各类拒绝原因。不得因任一门禁失败而再次调整范围或重抽。

额外对 v05c 与保留的 v05b DR 做完整配对核验。以 `base_index` 和候选序号为键，逐一比较**所有候选抽取**的序列、接受/拒绝结果及接受候选编号；每一对候选除航向外的全部采样参数必须相同。每一对接受场景的任务采样参数、几何与语义规划结果必须逐一相同，允许差异仅限初始航向及由其变化引起的 `family_id`。profile 指纹、文件哈希和生成目录路径另按来源字段核对，不把这些产物绑定字段误作物理规划差异。比较结果给出配对数、第一处差异及判定，并保存机器可读附件。任何缺项或未解释差异即停止报告，不进入 SITL。

## 验证、HD 与试生产

只从 v05c 新接受集按 r1.1 的原优先级重新选择 VP1–VP4、VR1–VR2；缺例时仍只按“进场方向 → K → 是否返航”的次序逐项放宽并记录，机数和意图不放宽。VP4 只修改 VP1 的 `terminal_hold_s` 为 1。v05b 的失败 VP1 保持失败，验证预算已用 **1/8** 次；v05c 后续所有 SITL 尝试累计至多再用 7 次，包括准许的起飞前环境故障重试。验证中的任一验收项失败，或再出现未解释参数差异，立即停止并报告；不进入 HD 或试生产。六项验证通过后，按 r1 的 HD 决策与试生产规则继续执行，在暂停 1 提交合并报告，并加入 v05、v05b、v05c profile 的构成及选择偏差对照。
