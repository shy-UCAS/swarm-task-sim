项目性质（照录本次上层要求 A 节）：

- 本项目是防御方视角的意图识别研究，生成器只产出带标签的合成轨迹数据集；

`propose_and_build`只构造一次attempt；`last_attempt_timing`只返回本进程遥测副本，绝不混入plan；`draw_summary`只从声明的确定字段投影。`final_failure`遵循R5 6.5/S分类：所有尝试确为集合空且无证明时approx_empty，混有路由/优化/仿真/核验失败为budget_exhausted；只有真实精确证书才proven_infeasible。`numeric_unresolved`、异常或未完成不能计作“已证明空集”。本项不预登记任何proven_infeasible合同。

### 3.2 精确扇区集合，不能把原型的近似判空当生产集合

新增接口：

```python
# v08/motion/area_search_geometry.py（新接口）
def radial_legal_table(ctx, target_id, *, outer_offset_m, rho_m): ...
def minimum_inner_offset(base_geometry, center, angles_rad, outer_offset_m,
                         inner_lower_m, *, min_gap_m=40.0, min_length_m=60.0): ...
def feasible_sector_cells(ctx, target_id, member_count, altitude_m): ...
def filter_entry_cells(ctx, target_id, chord_cells, sector_cells, outer_offset_m): ...
```

基础轮廓、中心和offset均取S；本项只接纳S已有圆、凸多边形及其buffer表示，不将多边形拟合成圆。先为720个方位计算径向**合法区间**，不是只在30个采样点验余量。对每个base约束，将 `sense*sdf-minimum`（sense=0时为`abs(sdf)-minimum`）≥0转成射线参数闭区间；世界取内侧区间，障碍/禁止层取外侧区间，交集保留所有连通段。用 `line_sublevel` 及补集、交集完成，端点用原精确SDF复核，不给余量加负容差。

从外端径向向外的终点取以外端为零、5m间隔上**第一个**对全部预警SDF≥55的点；搜索上界为所在合法世界区间端点，不是原型2500/3000m常数。更远设施可能再次形成禁止区间，必须证整个走廊位于同一base合法连通段，不能只验出口。径向条带延伸的端点为 `P_inner-rho*u` 与 `P_outer+rho*u`。此整段及出口走廊必须满足base。每个c有自己的inner，不能先按最低a_i0不通过就删掉实际抬高后可行的格。

对每个(μ,φ)枚举**有限完整的偶数c集合**。安全枚举上界由外偏移轮廓周长推导：相邻内端点间距≥40，因此 \((K-1)40\le P_{outer}\)，取 \(K_{max}=\lfloor P_{outer}/40\rfloor+1\)，\(c\le\lfloor K_{max}/N\rfloor\)。圆周长为\(2\pi R\)，凸多边形offset周长为原周长加\(2\pi b\)。这只是有限上界，不替代逐c精确判定，不使用原型`range(2,400,2)`。

给定c，条带角为

\[
\theta_k=\mu-\phi/2+(k+1/2)\phi/(Nc),\quad k=0,\ldots,Nc-1.
\]

用冻结 `radial_points_exact(offset_geometry(base,offset),center,angles)` 得端点。邻距指**欧氏弦长**，不是\(R\Delta\theta\)。先验外端最大邻距≤1.6rf。内偏移取满足全部内端邻距≥40、每条径向长度≥60的最小值。长度条件给有限上界：对每条射线取外端径向距离减60的点，计算其基础轮廓SDF，各值最小者为a_hi；若a_hi<a_i0则空。

圆形解析求解：设基础半径R、\(\Delta=\phi/K\)，

\[
a_i=\max\{a_{i0},\;40/[2\sin(\Delta/2)]-R\}.
\]

若超过a_hi，c不可行。返回前用实际端点重验所有不等式；只允许对解析根向可行侧取相邻浮点数，不降低40/60。

凸多边形用**一维分段代数区间求交**，不假设邻距随offset单调，也不以1m递增冒充最小值。实现如下：将buffer合入总offset；每条固定射线与offset边界交点的当前特征是平移边或顶点圆。平移边的径向距离为offset的仿射函数；顶点圆为 \(q+\sqrt{(a+b)^2-h^2}\)，q/h是顶点相对中心在射线上的投影/垂距。特征切换点由“射线与顶点沿相邻边法线偏移的位置重合”的两元线性方程求出。合并所有射线切换点，划分[a_i0,a_hi]。各小区间中把相邻距离平方减1600设为零，消去最多两个平方根得到多项式；求实根后必须回代原式、特征区间和根号正支，剔除平方引入的赘根。以端点和有效根分割区间，逐段中点判符号，求全部相邻条件的闭集交，取最左可行端点。浮点根用两侧符号括区间细化至相邻可表示数，选满足原始不等式的一侧；若无法认证根或边界归属，返回明确 `numeric_unresolved`，不能填成可行或静默当几何空集。该数值方法未经运行，成本和极近切换点的稳定性必须先过第3.7节，疑点见12节。

在求得最小a_i后，检验整个扇区内每0.5°射线的带与走廊；该格的每个c分别保存a_i及诊断。`feasible_sector_cells` 只返回c集合非空的格，排序(μ,φ)、c升序。0.5°协议证明的是登记射线条件；真实圆角/连接仍需精确曲线复核，不能宣称已证明射线之间所有连续面积无障碍。

S的bounding_radius取基础轮廓相对该中心的最大顶点距离（圆为半径）加外offset及已有buffer，bounds为center±此半径。不沿用原型`Ro+200`。按 `sector_area(geometry,32)` 求面积，再按U公式确定grid；该bounds同时决定网格原点，必须随S保存且用于名义与实测的同一冻结coverage。

### 3.3 从过境集合筛弦，再按三层均匀抽取

每次attempt先由原formation流和原宽度选择链确定slots；按 `intent='area_search'` 查询**完整过境弦可行集**。不能用原型“外缘点+β”造线。弦缓存自己的 `version='area_search-v20'`、目录 `area_search_v20`；继承完整 query_identity 几何、target、offsets和配置组成，不与transit/close_observation共用身份。单车道缓存的intent参数一起传到底，worker只读预建文件，miss进程内算；不并发覆盖磁盘缓存。

对每格，\(O\)为S的目标中心，\(u,n\)为`TC.frame(theta)`，参考直线为\(p(x)=O+h n+xu\)。取`line_sublevel(base,O+h*n,u,a_o)`沿进场方向的**第一个**边界交点Q，不能漏掉h变成过中心的弦。需要在所选过境格的前向行程内实际可达；仅无限延长线相交不算。令 \(v_r=(center-Q)/\|center-Q\|\)，β为u到v_r的有符号夹角；用atan2叉积/点积算，筛\(|β|\le45°\)。再筛存在至少一个扇区格满足\(|wrap(α_Q-μ)|\le0.4φ\)。把对应扇区列表挂在该弦格下；无对应扇区的格删除。格去重按S `(theta_idx,h)` 身份，不按c个数复制。

新增 `draw_hierarchy(entries,rng)`：entries是排序的`[(chord,[(sector,tuple(cs)),...]),...]`。依次仅调用 `rng.integers(len(entries))`、`rng.integers(len(sectors))`、`rng.integers(len(cs))`，返回(chord,sector,c)。三层各自均匀，不能对所有三元组整体均匀。空集不消耗shape、直接`area_search_entry`普通失败。抽完再沿S对所选格的collect_D候选作原shape整数抽取；不得在这三次之间插入D、旧K/logit或不用的过境曲线抽签。

新geometry/集合计算不读随机数；新抽样只在area_search显式入口。旧intent生成器从未进入它，原shape/formation/connect/speed流的调用序列和状态必须与S逐项相同。证明材料包括：调用位置diff、假rng的三层调用测试、五旧意图同键抽签日志/最终状态对照、两道字节门禁。不能以“同seed”代替消耗证明。area_search对transit同键不保证选同弦，因为其候选子集不同；六意图配对报告这件事，不能为了同弦改变均匀分布。

### 3.4 进场、分块、圆角和独立出口

1. 选中格的集合点C及各槽位沿S计算。调用生产 `plan_starts(..., route_fn=...)`，route_fn走 `route_to_slot`/`entry_planner`，路由目标是**圈外集合槽位**；随后固定直线沿原u进场到Q槽位。`entry_planner`禁止提前进入目标预警圈，因此不能把圈内Q直接当作该可见图查询终点。完整进场曲线的终点才是Q槽位。集合之前保持目标预警外10m；目标入圈前100m对齐、穿越带±10m直线都按S检查。
2. Q槽位严格使用`Q + longitudinal*u + lateral*n`，沿S居中offset，不用原型纵列`Q-j*b*u`替代。每个成员开始离开共同直线的**实际圆角切入点**必须已经在目标预警层内且穿越带结束；完整穿越带不含转弯。Q本身或槽位在圈外时不得先分开再声称“编组已入圈”。这项与长纵列的可行性疑点见12.1，不能偷偷移Q。
3. 每块连续c条，块b含`b*c..(b+1)*c-1`。块按第一条外端在进场横向轴n上的投影升序，投影相同按块索引。横排/梯形slots按lateral升序，同侧向值按longitudinal升序、再按原slots.order序；纵列按longitudinal降序（前到后），再按原order。使用原formation随机分配出的成员身份，不按成员初始坐标重新排序。
4. 每块顶点依次为`outer[k],inner[k],inner[k+1],outer[k+1],outer[k+2],inner[k+2],...`；偶数c保证末点为外端。不得省整条扫描条带或把c改成奇数。最后一条外端沿同射线接第3.2节出口E，外端与E共线时删除多余共线顶点但保留相位锚点。
5. U形连接包括同侧两端的两个圆角及中间短直线。两圆角用该连接实际弦长d算`0.5*(d-6.5)/1.10`，必须≥15；调用原fillet_route验每段切线侵占及最短直线6m。不能从“条带距40”推断所有非圆形连接必定满足切线条件，实际不合返回`area_search_route`。
6. head顺序沿参考原型：`[Cslot,Qslot,first_outer]`的转角半径先30/30；仅当圆角几何放不下时试30/15；仍因Q至first_outer太短放不下时省first_outer，直接接first_inner、Q处半径30。这只是**同一组固定顶点的确定性圆角可放置判断**，不更换抽签，不以base/预筛失败为理由尝试另一个head。若省略first_outer，实际首次有效进入S之前仍需完整检查；条带块索引不变并明确`first_outer_omitted`。30/15来源为原型；无来源的更小半径、更早分开、平移Q、横列重排均不得加。
7. `fillet_route`接受None半径时的行为不能当作“保留折角”：S可能直接跨过该顶点。本项非共线转角都给明确半径，零长/共线顶点由显式规范化删除，见证保留映射。沿ctx曲线采样间距0.5m采样；采样折线每条弦用base精确最小余量复核，原弧的极值也以解析圆弧及约束特征点复核，不能只检查端点。失败类型为route/shape audit，不能再抽格。

不得在这一部分加入成员间距拒绝或时长拒绝。允许原entry_planner内部固定路由候选协议，不能再包一层“换格—换c—换队形”的循环。路由失败为`start_route`，确定几何/圆角失败为`area_search_route`，选中格没有后续可行改造时这次attempt结束，统一20次预算。

### 7.2 成员分开后的作业段Fréchet

旧五意图原函数路径和结果不动。area_search新增scope `area_search_warning_entry_to_last_exit_v20`。由于没有公共偏移中心线，显式以共同绝对时刻上的名义编组平均位置作为新意图的before：\(c_b(t)=N^{-1}\sum_i p_i^{ref}(t)\)，after仍为原“编组位移”形式 \(c_a(t)=c_b(t)+N^{-1}\sum_i[p_i^{opt}(t)-p_i^{ref}(t)]\)。未释放/已结束成员按原TimeReference端点保持，不额外延展速度。不要把某一成员的多条扫描路径当公共中心线。

before/after各自用成员warning唯一入/出事件截取“最先进入至最后离开”的共同时间窗；名义事件由原crossing_analysis弧长映射，优化参考用S的精确几何弦交点及该弦时间插值。不能要求平均曲线本身只有一次入/出，平均位置未必沿成员扫描。10Hz公共时刻并入各边界时刻，求平均曲线后，按各自几何累计弧长5m重采样，重复空间点去重，终点保留。该5m源自R5 14.3/S FRECHET_SPACING_M，不按停留时间加权。

每族成功且可比较branch两两离散Fréchet；除**原公共横向间距**一次；合并所有族所有有效对后取一个中位数，不能先每族取中位数。报告可比较对数、N/A原因、before/after数值与端点。分开后该指标意义较弱，U要求⑥重新定义多样性，本项不以此推出意图可辨识结论。

class IntegerRng:
    def __init__(self, answers):
        self.answers = iter(answers)
        self.calls = []

    def integers(self, high):
        self.calls.append(int(high))
        value = next(self.answers)
        if not 0 <= value < high:
            raise AssertionError("invalid scripted draw")
        return value

## 12. 疑点与建议（不自行改动要求）

### 12.1 中心Q在外缘不保证长纵列全部已经进入预警层

S `formation_slots` 纵列以中心前后对称分布，最大纵向偏移为\((N-1)b/2\)；原型却用`Q-j*b*u`，且未走生产弦。U把中心Q固定在外缘、深度12.5+ρ，不能推出全部槽位及圆角切入点均在预警层内。

解析反例：圆形基础半径100、warning offset400、alert offset200、高度100，rf50、ρ40，外缘半径447.5。过境候选取u=(1,0)、h=315，避开alert+10的半径310，第一交点\(Q=(-\sqrt{447.5^2-315^2},315)\)，\(|β|=\arcsin(315/447.5)<45°\)。12机、b24的居中纵列后槽位为Q−132u，其半径超过warning半径500。即便中心满足筛选，后排仍在圈外；实际圆角更可能更早开始分开。

**处理：** 指令保留U的Q和S槽位，精确记录并按普通area_search_route拒绝违反“入圈后分开”的候选，绝不悄悄平移Q/收拢/变队形/提前分开。不把原型16/16视为此问题已解决；若导致骨架检查点触发，将反例和真实键交审查。建议上层明确“编组Q还是逐成员分开站点”及允许的几何调整，本指令不选择其中一种新设计。

### 12.2 两个集合分别200/200非空不证明筛弦交集非空

圆形简化下，过境合法弦要求\(|h|\ge R_{alert}+10+\text{横向展宽}\)，β≤45又要求\(|h|\le R_{outer}\sin45°\)。上下界可能颠倒。还要满足Q的中间80%、世界/其他设施及slots条件。U的“约200/200、筛空接近0”是需验证预期，不能作为数学保证。按第3/5节实测，不为追成功率扩大45°/φ、改弦网格或剔除合同。

### 12.3 原型c/inner/走廊算法含近似与任意截断

原型用RΔ近似间距、1m递增inner、c<400、出场2500/3000m限长、30点带内采样、Ro+200包围半径。这些不足以满足U的最小可行inner及精确base余量。本文按欧氏弦距、解析/分段代数区间、世界界定的出口和精确弦余量替换；不会沿用原型0.9s作为本算法已测成本。多边形最小根的稳定性和成本待快速检查，若不能认证，列numeric_unresolved，不放宽要求。

### 12.4 圈内Q不能直接作为entry_planner查询终点

S planner明确将目标warning外10m列为障碍限制。把圈内Q直接传入会正确拒绝。本文用生产planner到圈外C，再沿同一选中弦到Qslot；“终点为Qslot”指完整进场，不是可见图的goal。这样保留S禁止提前入圈机制与U整体意图，不新增随机中间点。

### 12.5 coverage的restricted在冻结代码中仅为障碍掩码
