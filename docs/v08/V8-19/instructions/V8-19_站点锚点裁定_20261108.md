## 2. 修正方法（替换第 2.2 节中"合成到达表"一段的实现口径）

1. **锚点：** 选中的原始站点 s_d 是驻留站点的唯一标识。在拼接到达表中：
   - incoming 部分取 `incoming.curve.s` 与 `incoming.t_nodes`，但把**最后一个弧长值替换为 s_d 本身**；
   - outgoing 部分去掉首点，弧长为 `s_d + outgoing.curve.s[1:]`，时间为 `outgoing.t_nodes[1:] + (T₁ + T_d)`。
2. **替换前先检查：** `abs(incoming.curve.s[-1] - s_d) <= 1e-9 * max(1.0, s_d)`，不满足就抛 `ValueError`。这条检查用来防止真的几何不一致（例如切分点不在曲线上），不是放宽。
3. **分侧映射：** `DwellReference.time_at_s` 以 s ≤ s_d（锚点值）为界分侧。incoming 一侧在替换后的表上插值，outgoing 一侧沿用 `s_d +` 的偏移，所以 s_d 精确对应到达时刻。
4. **不变的部分：**
   - 驻留空间点 P_d 仍取原插值，不吸附；
   - 冻结的 `member_nominal`、`NominalPVA` 不改，incoming / outgoing 对象本身不改，只改拼接表；
   - 不重抽时长，不改随机数消耗；
   - 结束时刻 `normalized_end` 不变；
   - 驻留语义直线仍用 t_a、t_b 两个时刻，不受影响；
   - 预置测试与阈值不改。
5. **自加测试补一条：** 把 incoming 最后一个弧长人为改成 s_d + 1e-6 m，应当抛 `ValueError`。
