### 2.1 新接口与切分规则

以下是**本项新增接口**，不是 S 中已存在的函数：

```python
# v08/motion/dwell_nominal.py
def split_member_plan(member_plan, s_d): ...
def normalized_end(release_s, incoming_s, dwell_s, outgoing_s): ...
def compose_dwell(incoming, outgoing, dwell_s): ...
def member_nominal_with_dwell(member_plan, dwell, *, guidance=None, sim=None): ...
def dwell_lines_from_skeleton(skeleton, maps): ...

# v08/motion/close_observation_numeric.py
def dwell_grid(s_from, s_to): ...
def admissible_dwell_mask(stations, member_s, points, semantic_ranges,
                          warning, alert, base): ...
def draw_dwell(stations, rng): ...
```

`split_member_plan` 返回两个 `MemberPlan`，`dwell=(s_d,T_d)` 中的 \(s_d\) 是该成员**完整曲线**从初始位置算起的弧长，不是编组中心线弧长。用原顶点累计弦长定位，按线性插值插入精确分割点，左右各保留一份；不向最近节点取整，不改变几何。保留高度、成员、段号和释放延迟；左右 `end_s` 改为各自几何长度（此字段单位是米），`stops=()`。首段速度折点保留原 \(s<s_d\) 的项；后段首项取原右连续分段速度在 \(s_d\) 的值并放到 0，后续折点为原 \(s>s_d\) 的项减 \(s_d\)。原折点恰在切点时只在后段首项出现一次，不重抽 speed。

左右各用原 `member_nominal(..., guidance=reference_guidance())`，得到 `incoming/outgoing`。这样进场末端和离开起点速度都是 0。两个原 Nominal 的 `hold_s` 不插入中间；合成末端保持只取一次原 sim 配置值。`release_s` 只取 incoming 经 `release_us` 按帧取整的结果；outgoing 的 release 不作为新的释放事件，其局部时间只平移，不能再对 \(t_a+T_d\) 取整。

`make_curve` 实际只验证点列，不自动加密（S）；生产原曲线已满足最大弦长。切点若造成小于冻结 `MIN_CHORD_M` 的弦，报告 `close_obs_reference` 普通失败及原始弧长，不自行把驻留点吸附到别的可行点。两段长度均须正且 `member_nominal` 时间有限。

### 2.2 合成时间、PVA 与浮点端点

`compose_dwell` 返回对象 `DwellReference`，至少公开：`incoming/outgoing`、`release_s/end_s/travel_s/hold_s/altitude_m`、`arrival_s/departure_s/dwell_s/dwell_station_m/dwell_point_xy`、`curve.s/curve.xy/t_nodes`、`pva(t_abs)`、`time_at_s(s)`。`curve` 是两段几何拼接去掉重复驻留顶点后的严格递增弧长表；它**不是**可以传给原 `NominalPVA` 或 `sample_nominal` 的普通 Nominal。原对象不改。

令 \(r=\text{incoming.release_s}\)、\(T_1=\text{incoming.travel_s}\)、\(T_2=\text{outgoing.travel_s}\)：

```python
duration_sum = (float(incoming.travel_s) + float(dwell_s)) + float(outgoing.travel_s)
r = float(incoming.release_s)
e = r + duration_sum                       # 必须括号内先求总时长
T = e - r                                # 与 Prepared._member 完全同一运算
assert e == r + T                         # 与 Prepared.decode 生成的 end_s 相同
ta = r + float(incoming.travel_s)
tb = ta + float(dwell_s)
```

将上述运算封装为 `normalized_end`，返回 `(e,T)`，由 `compose_dwell` 调用。`TimeReference.end_s` 直接使用上述 `e`，`travel_s` 使用 `T`；不写成 `(r+T1)+Td+T2`，也不让 outgoing 自带 release/hold 参加求和。数学上 \(e-r=T_1+T_d+T_2\)；浮点下原始三项和与 `e-r` 可以相差 ulp，必须同时记录 `duration_sum`、`T` 与差值，按运算舍入界比较，不用近似比较放宽 `check_physical.fixed_time`。**真正要求逐位相同的是输入参考 `e` 和解码后的 `r+(e-r)`。** 详见 12.1。`compose_dwell`/生产入口拒绝非有限、非十分秒网格或域外时长：用 `n=round(Td*10)`、`Td==n/10`、`200<=n<=1200` 校验，非法抛 `ValueError`；不做浮点 `%0.1` 比较。

合成 `pva` 标量和数组都支持，位置/速度采用：到 \(t_a\) 为 incoming；开区间 \((t_a,t_b)\) 为 \(P_d,0,0\)；从 \(t_b\) 起为 outgoing 在局部时间 \(t-t_b\) 的原弦内公式。调用原 `NominalPVA` 时可对 outgoing 的 Nominal 作仅 `release_s=0` 的副本，避免把小局部时间再加一个无关 release；实际时间轴只做 \(t-t_b\) 平移。\(t<r\) 与 \(t>e\) 显式返回对应端点、零速度/加速度；\(t=r,e\) 精确给对应端点和零速度；\(t=t_a,t_b\) 精确给 \(P_d\)、零速度，边界加速度按各侧原式，不承诺名义加速度连续。位置、速度连续；优化样条另满足既有连续性及动力学硬检查。

合成到达表：incoming 的全部 `curve.s/t_nodes`；outgoing 去掉首点后弧长加 \(s_d\)、时间加 \(T_1+T_d\)。驻留站点只出现一次，对应 **到达时间 \(T_1\)**。因此：

```python
ta = float(np.interp(s_d, nom.curve.s, nom.t_nodes)) + float(nom.release_s)
```

与 S `turns_from_skeleton` 是同一插值口径，不能调用 S `Nominal.time_at_s` 的最近节点实现。驻留造成站点—时间映射的跳跃；一般站点的 `DwellReference.time_at_s` 必须分侧：\(s\le s_d\) 用 incoming 插值加 \(r\)，\(s>s_d\) 用 outgoing 插值加 \(t_b\)。不得在跨驻留的拼接表上对任意站点插值，把 \(T_d\) 摊到第一条离开弦。到达表只供驻留站点的上述精确节点映射及诊断；报告/Fréchet 用分侧方法。

\]

## 12. 疑似设计问题、代码冲突与处理意见

### 12.1 总时长等式的浮点含义

U要求 \(e-r=T_1+T_d+T_2\)，并指出 `fixed_time` 陷阱。S `_member` 以 `T=e-r` 存时长，`decode` 用 `r+T` 重建结束时刻；`check_physical` 用严格 `==`，不接受时间容差。三项浮点和与“加release再减release”并非恒等。例：`r=20.1,T1=4.1,Td=20.1,T2=52.4`，左结合结束96.7，解码96.69999999999999；括号总时长76.6得到后者。

**处理：** 保留S严格检查，按2.2规范计算、记录原和及规范时长；解析测试对可精确表示的4+20+4用严格相等，对该浮点反例检查解码逐位一致。不能把所有随机浮点组合的“原始总和逐位相等”另设门禁；若规划方确实要求这项更强等式，需要裁定数值表示，执行方不得通过修改T₂或hard check自行满足。

### 12.2 “同时驻留”不是同一绝对时间约束

U D.3.4同时规定各成员ta按自己的名义时间、释放延迟沿用，只有“基本同时”，未给差值阈值。两段重算速度会改变到驻留点的行程时间。

**处理：** 同一组站点、同一Td、各自ta；报告跨度，不加同步等待、不重排release、不修改求解变量。若要所有人具有共同长度≥20s的重叠驻留区间，这是额外设计要求，须另裁定，不能宣称本项已保证。

### 12.3 单个弧长节点无法同时代表驻留到达和离开

重复s节点上 `np.interp` 会取后一个值；直接拼重复驻留节点会把ta映射成离开。只用严格递增表则跨平台的插值会把驻留时长摊入邻弦。S `Nominal.time_at_s`又是最近节点，与 `turns_from_skeleton`不同。

**处理：** 到达表仅在驻留节点按S公式映射；一般站点用新对象分侧插值；两侧 `semantic_lines` 分别生成后平移；Fréchet和五段报告显式接入。这是新参考适配，不改S原对象。抵近观察turn_ranges为空；未来同时有驻留和掉头时要另审一般映射，不能假定本项解决多段/混合意图。

### 12.4 上层“完全复用过境”与缓存隔离

S底层车道已有intent，上层弦查询/identity没有；直接调用会混用 `transit_v16`。S `formation_probe_sequence` 和预建默认也创建transit mission。

**处理：** 只参数化上层并显式分派；旧默认身份逐字不变，新意图identity/cache目录隔离。相同几何重复缓存是U明确要求的结果；不以复用为名修改既有文件或用新intent改旧qid。

### 12.5 旧预筛和冻结抵近观察并不是一张检查表

S `check_transit` 要求全窗无驻留；冻结close_observation仅取 `observation_dwell/no_revisit`，不查 `no_dwell_window`，也**不查目标预警进入恰一次或首帧目标层0**。U C中o11_d0已经证明冻结通过不代表一次进入。

**处理：** 新预筛直接组成表，不套过境passed；最终冻结核验之外额外复算进入次数。`observation_dwell`指在tl==1掩码上检出，不是“全窗只能发生这一次驻留”。首帧目标0由新意图构造与预筛保证；保留端事件再查一次。不能修改冻结判据补条件。

### 12.6 报告原函数会漏掉新时间段

S `transit_report.group_reference_curves`直接调用无驻留 `member_nominal`，phase诊断也依赖旧时间表；直接复用将错配优化位移、速度与时长。

**处理：** 新意图使用已建立的驻留参考与分侧映射，几何Fréchet算法原样保留；旧四意图继续原路径。参考在边界处只保证p/v连续，名义a可跳；不得误写“原NominalPVA是C²参考”，优化样条的连续性由原表示保证。

### 12.7 旧止损与本项上层列表不同

S `skeleton_transit.write_outputs`默认增加直线回退>50%；佯动后来骨架墙钟60分钟；突入有o34_d3排除。本项U明确骨架30分钟、无排除、止损列表没有直线回退项。

**处理：** 新意图显式分派到公共骨架检查点，加U的30分钟墙钟；回退只报诊断。未改过境旧检查点，不将历史60/90分钟或排除名单移植。本项重复跑旧意图门禁时按旧意图原口径运行。

### 12.8 固定Pd可能使间距问题无法靠优化挪点解决

两条等式锁死驻留位置；若某实际派生队形在该点的成员距离本来小于优化硬间距，solver无法移动Pd解决。U驻留集合没有指定成员间距谓词，R5又禁止骨架间距拒绝。原型成功不证明所有曲线/队形组合。

**处理：** 不新增驻留点间距筛选，不改点/队形/分布；作为普通优化失败记录。最大编组完整约束smoke与报告须观察驻留期间间距、等式一致性和失败率；若成为系统性问题，带具体Pd、约束和解析距离进入裁定，不自己引入间距下界或改同步规则。

### 12.9 序列化文档字符串比实现保证更强

S `save_intent_contract`顶层有白名单，但 `plan_to_record`仍保存嵌套proposal/witness；`det_attempts`也只去掉顶层timing/traceback。仅照抄“有白名单”的说明无法证明新字段无计时/路径污染。

**处理：** 新意图从对象入口开始逐层投影，落盘前禁止未知字段、独立递归扫描；旧意图不统一重序列化，避免改变合同bytes。缓存qid可作为确定性身份；cache hit/miss和文件位置绝不入合同。

### 12.10 r4的旧驻留引导、终点与成本表述

R4 6.3.3停止点引导被R5 6.3.8(b)的时间等式覆盖；R4“结束位置不限”被本项final/outside覆盖。R4离开60m由本项SDF条件和过境终点自动推出，不需多加随机尺度。U C原型简化三处不能作为生产满约束成本证据；C18早期按人数外推已被C18c撤销。

**处理：** 沿2–7节实现和最大查询实测；不新建 guided 停留机制，不加入旧1800s预算。穿出式出口记P3，④再设计其他出口。没有来源的ta同步误差、检测窗口偏差、成本外推安全系数都不补造常数。
